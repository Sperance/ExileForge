# #489 [Баг] В окне модерации все же раздельно отображай всех героев с подробной информацией. так же проверь как работает штука "В с…
Пакет: 8 Модерация; статус: решено

## Разбор
См. audit/work/triage/moderation.md (раздел #489).

## Вопросы и ответы
1. Вид — карточка на каждого героя (рек.) / аккаунты с полными строками / переключатель. Ответ: карточка на героя, логин подписью.
2. Поля — класс, уровень, Мощь, присутствие; санкция и тестировщик; гильдия, золото, дата создания; версия клиента и сервер (все).
3. «В сети» — пульс приложения (рек.) / последняя команда героя. Ответ: последняя команда героя (Hero.lastSeenAt, шаг 5 мин), без нового пульса.
4. Формат — как в Telegram (рек.). Ответ: да: «в сети», «был(а) только что», «N минут назад», «сегодня в 14:05», «вчера в 21:30», дата; один форматтер в core везде; живой такт.

5. Макет (mockups/489/moderation.html) — А «Паспорт» (рек.) / Б «Плотная строка» / В. Ответ: Б: три строки без подписей, Мощь справа, присутствие у логина.
6. Давность — без глагола («14 мин назад», «вчера в 21:30»), «в сети» (рек.). Ответ: да.

## Решение
Сервер: страница moderation/rows — единица героя (поля с default, без вайпа). Клиент: карточка на героя (логин подписью; класс, уровень, Мощь, присутствие, санкция, тестировщик, гильдия, золото, дата создания, версия клиента и сервер); присутствие — по Hero.lastSeenAt (у аккаунта — max по героям), окно «в сети» по rules.online; один форматтер давности в core (склонения plural, сегодня/вчера/дата) вместо seenText/seenShort/presenceText; такт rememberServerNow. Макет: mockups/489/moderation.html, Б.
