# #415 [Баг] Что такое метки?
Пакет: Древо и подсказки; статус: решено; сервер: тексты по желанию; дизайн: желателен

## Разбор
Причина: Метки - механика одного умения MARK_OF_RUIN ('Клеймо распада'); узлов с меткой 2 (SHA_K9, WIT_K9), термин путается. stat.detail.STOCK_MARK_EFFECT виден только в разборе героя; строки узлов древа не нажимаются (TreeDetails.kt:169,190).
Предложение: Нажимаемые строки узла -> StatDetail 3-4 ч; переименование терминов - сервер.

## Вопросы и ответы
1. Как объяснить? Ответ: нажимаемые строки - касание открывает имя характеристики и StatDetail.paragraphs (как в разборе героя).
2. Термин? Ответ: «метка» только одна: умение «Клеймо распада» -> «Метка распада» (и книга); «Метка снайпера» -> «Прицел снайпера» (и книга); узел «Ведьмина метка» -> «Ведьмин сглаз»; «Меткое слово», «Меткость» не трогать; en соответственно.
3. Где нажимаемые строки? Ответ: везде, где строки характеристик - один компонент строки (древо, Атлас, карточки предметов, дары).

## Решение
Доп. ответы: переименовать и прочие «метки»: «Метка завоевателя» -> «Знак завоевателя», «Метка еретика» -> «Знак еретика», сила «Клеймо» (Хватка клеймителя) -> «Метка клеймителя», en соответственно; дописать stat.desc/stat.detail характеристикам Атласа на всех языках, чтобы их строки нажимались.
Клиент: ModifierLine нажимаемый -> лист описания характеристики; сервер: переименования в locale ru/en (+ клиентские словари, если есть).
Ответ 2026-10-22: сила «Меченая добыча» -> «Загнанная добыча», в шаблоне «метит врага» -> «загоняет врага»; en уже «Tagged Prey». Слово «метка» остаётся только у настоящих меток.
