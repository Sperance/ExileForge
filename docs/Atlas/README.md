# Атлас: развитие походов

Атлас — отдельное дерево из **576 узлов**, отвечающее за походы и добычу. Его очки не являются очками пассивного дерева персонажа. Максимум доступного прогресса по очкам — **132**.

## Получение очков <a href="#получение-очков" id="получение-очков"></a>

Правила задают по одному очку за достижения типов: босс, редкая карта, Ваал, босс-раш и башня. Достижения имеют собственные ключи и не превращают повторное выполнение одного и того же условия в бесконечные очки.

## Выбор пути <a href="#выбор-пути" id="выбор-пути"></a>

Старт Атласа доступен как корень. Новый узел должен быть связан с уже открытым путём, требовать доступное очко и существовать в графе. Узлы бывают малыми, значимыми и ключевыми; ключевой эффект может менять способ прохождения, поэтому читайте его свойства целиком.

## Возврат <a href="#возврат" id="возврат"></a>

По умолчанию стоимость возврата одного узла: **500 + 50 × уровень героя** золотом. Альтернатива — **одна сфера сожаления** за узел. Полный сброс стоит столько же, сколько возврат всех выбранных узлов. Обычный возврат не должен разорвать связность оставшегося дерева.

Например, на 20-м уровне один узел стоит 1500 золота; возврат пяти — 7500. Это расчёт формулы текущего контента.

## Каталог <a href="#каталог" id="каталог"></a>

Свойства Атласа используют собственную группу характеристик. Параметр ускорения возвращения босса ограничен потолком **90%**. Не все бонусы Атласа видны как увеличение характеристик героя: часть применяется к генерации похода и наградам.
