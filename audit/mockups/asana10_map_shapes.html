Новые формы карт похода

ASANA-10. Сейчас все 150 зон - 72×72 (campaign.json "size": 72), два стиля MapStyle.CAVERN/HALLS (MapGenerator.generate). Решение владельца: 48–64 клетки по типу зоны, цель 3–5 минут на заход, 2–3 новых шаблона по биому. Ниже - вид сверху, как мини-карта drawExplored; каждая карта сгенерирована процедурно, «Другой сид» пересобирает.

A
Комнаты и коридоры

+ Ясный маршрут, у каждой комнаты своя роль (сундук в тупике, алтарь, торговец), легко сделать «комнату-событие». − Похоже на нынешний HALLS; без петель - много возврата из тупиков.

Склеп Забытых · 56×56

ФОРМА

  • Размер 56×56 (залы: склеп, храм, руины, шахты, цитадель - нынешние halls).
  • 8–10 комнат 6–11 клеток, коридоры шириной 2, остов-дерево + 1–2 петли, чтобы не ходить назад.
  • Вход - комната у края; босс - самая дальняя по пути комната, выход за ним.
  • Сундуки - в тупиковых комнатах (награда за крюк); точки интереса - по одной на боковую комнату: алтарь, торговец, узел, фонтан.

ДЛЯ ГЕНЕРАТОРА

  • Новый MapStyle.ROOMS; комнаты - готовые места для features (RoomSpot) - сейчас объекты вырезают комнату за стеной сами.
B
Кольцо вокруг арены босса

+ Босс виден с первой минуты, путь всегда к нему; две дороги по кольцу - выбор и нет тупиков; арена - честное место для боя. − Одна форма на все карты быстро узнаётся; нужен «замок» ворот, иначе игрок идёт сразу к воротам.

Пепельная пустошь · 52×52

ФОРМА

  • Размер 52×52 (открытые биомы: пустошь, степь, пустыня).
  • Неровное кольцо шириной 5–8 клеток, внутри - круглая арена ~17 клеток в скальном поясе.
  • Вход - снизу на кольце; ворота арены - напротив, сверху: до босса пол-кольца в любую сторону.
  • Сундуки - в нишах снаружи кольца; точки интереса - на самом кольце, по одной на четверть.
  • Ворота открываются после N стай или рычага (как RoomSpot.lever) - иначе форма теряет смысл.
C
Острова через воду с мостами

+ Самая «новая» на вид, использует уже готовую воду биома (Liquid), мосты - естественные узкие места для засад; боковые острова - награда за крюк. − Мосты шириной 2 мешают обходу стай; вода съедает площадь - ходить меньше, но и видно меньше пола.

Чёрная гать · 60×60

ФОРМА

  • Размер 60×60 (болота, побережья, лава/лёд - биомы с liquidOf).
  • Цепь из 5 островов от угла к углу + 2 боковых; мосты шириной 2 - новый вид клетки (или пол поверх воды).
  • Вход - на первом острове; босс - на последнем, самом большом.
  • Сундуки - на боковых островах; точки интереса - по одной на средних островах.

Ориентир времени - грубая прикидка, не замер: шаг героя ~3 клетки/с, путь с обходом ≈ 1,6 × кратчайшего, стая ~10 с, босс ~30 с, объект ~5 с. Нынешняя 72×72 пещера на скрине ASANA-10 - 67 монстров, 81% исследовано, 0 сундуков и фонтанов. Числа стай и объектов - пример для макета, не баланс.
