# #395 Грубый камень в сумке в Прочем
Пакет: Ремёсла; статус: решено; сервер: да; дизайн: нет

## Разбор
Причина: BagPanel.kt:86-96 bagSections: только Item.MATERIAL -> Материалы, остальное в Прочее. Сервер content/items.json:3-19: STONE_ROUGH, STONE_POLISHED - category STONE_STOCK; WOOD_LOG (Валежник) - WOOD_STOCK. Наследие старого контента. Клиент использует STONE_STOCK только для чипа crafts.group.STONE_STOCK (JobGroups.kt:38).
Предложение: на сервере перевести три предмета в category MATERIAL (подкатегория MINING/WOODCUTTING или своя STONE/LOG); вайп не нужен. 1-1,5 ч.

## Вопросы и ответы
1. Где чиним. Ответ: в контенте сервера (рекомендовал).
2. Подкатегория. Ответ: свои группы «Камень» (MATERIAL/STONE) и «Древесина» (MATERIAL/LOG) (рекомендовал).

## Решение
Сервер items.json: STONE_ROUGH, STONE_POLISHED -> category MATERIAL, subCategory STONE; WOOD_LOG -> MATERIAL, LOG. Убрать мёртвые STONE_STOCK/WOOD_STOCK. Клиент: ключи групп crafts.group.* под новые коды (Камень, Древесина) во всех языках, JobGroups. Проверить тесты контента (CraftContentTest, StackSourcesTest). Вайп не нужен.
