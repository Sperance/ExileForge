# #525 [Баг] Проверь перед входом в зону Ваал модификаторы написаны одни, а после входа в Ваал и просмотре модификаторов - они стали…
Пакет: 1 Поход: правила захода; статус: решено

## Разбор
См. audit/work/triage/expedition.md (раздел #525).

## Вопросы и ответы
1. Показ внутри Ваал — варианты: разделами (рек.) / итог и на портале / разделами + сумма. Ответ: разделами.
2. «Сила модификаторов карт» Атласа усиливает строки Ваал — да (рек.) / нет. Ответ: да.
3. Штраф акта и сделки алтаря переходят в Ваал — да, как сейчас (рек.) / только Ваал + карта. Ответ: да, как сейчас.
4. Заголовки — «Зона Ваал / Карта под порталом / Сделки алтаря / Атлас» (рек.) / короче / подробнее. Ответ: рекомендованные; штраф акта строкой «Штраф сопротивлений акта: −N%» в разделе карты.
5. Портал показывает те же усиленные числа — да (рек.) / база + «Атлас +N%». Ответ: да.

6. Макет (A разделы / B вкладки / C свёртки) — ответ: ни один, заново: все модификаторы — один общий список сумм по статам, каждая строка-сумма раскрывается стрелкой справа и показывает, откуда что (Ваал, карта, штраф акта, сделки алтаря, Атлас, скарабеи, Влияние, древо гильдии, зелье). Скарабеи/Влияние/гильдия/зелье — тоже внутри общих модификаторов.
7. Зона без карты-предмета — источник «Зона под порталом» (рек.). Ответ: да.
8. Пометка силы Атласа — сноска «с силой Атласа +12%» (рек.). Ответ: да.
9. Второй круг макета — A фраза-сумма с подсписком (рек.) / B группы / C по величине. Ответ: A.
10. Портал — свои строки + свёрнутый «Итог с картой» (рек.) / итог / только свои. Ответ: свои + «Итог с картой».
11. Порядок — по источникам (Ваал в порядке броска, потом карта и прочее), всё свёрнуто (рек.). Ответ: да.
12. Строка с одним источником — без стрелки, источник мелкой подписью (рек.). Ответ: да.
Без вопроса (как в макете): штраф акта входит долей в суммы стихий и хаоса; источник на обычной карте — «Карта»; заголовок «Модификаторы» в обоих окнах.

## Решение
Правило (rules + сервер): ATLAS_MAP_EFFECT усиливает и строки Ваал (RULES_VERSION). Клиент: окно модификаторов — один общий список сумм по статам; строка раскрывается стрелкой справа со списком источников (Зона Ваал / Карта под порталом или Зона под порталом / Штраф сопротивлений акта / Сделки алтаря / Атлас / скарабеи / Влияние / древо гильдии / зелье); сноска «с силой Атласа +N%»; портал показывает те же усиленные числа. Макет: mockups/525/vaal-window.html, вариант A (второй круг).
