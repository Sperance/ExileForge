## #583 Характеристики в бою считаются странно, всё должно биться по итоговым суммам

1. **Суть.** В раскрытии сдвинутой строки «база + слагаемые» не равны числу строки.
2. **Где.** HeroSummary.kt:293-301 (`ChangeSources`), :309-338 (`StatRow`, :321 - что печатается в строке); StatsSheet.kt:164-174
   (`fightParts`); core `campaign/combat/BattleTick.kt:256-260` (`heroBody`/`heroLines` - из чего реально собрано тело героя в бою);
   `campaign/combat/BattleViews.kt:90` (`Battle.effects` - что попадает в `FightHud.heroEffects`).
3. **Корневые причины (несколько, все подтверждены кодом):**
   - a) **Вклады боя - не числа, а фразы строк эффекта.** `fightParts` кладёт `SkillText.statLine(stat, op, value)` - полное
     предложение («+20% к увеличению брони», «на 10% больше…») рядом с абсолютным числом (броня 906). INCREASED/MORE в сумму не
     складываются в принципе.
   - b) **Не все источники боя показаны.** Тело героя = `lowLife` + `powers.standing` (силы уникалок) + заряды (`heroCharges.lines()`,
     `chargeLines()`) + условные строки (`model.conditional(conditions)`) + эффекты + ауры врагов (`.under(auras())`). В `fightParts`
     идут только `heroEffects`, да ещё без флаконов с истёкшим сроком, Разлома и стаков Предначертания (BattleViews.kt:90).
     У Марадёра с «Стойким кличем» заряды выносливости (снижение физ. урона, сопротивления) - вклад без строки.
   - c) **Строка и «Итог» печатают разные величины.** Строка (:321) - для брони/уклонения процент защиты (`StatLimits.defence`), для
     сопротивлений - действующее под пределом (`limit.effective`, 75%); «Герой без похода» и «Итог» (:294-296) - сырое значение листа
     (`rowValue(key, value)`): броня 1368 вместо «41%», сопротивление 86% вместо 75%.
   - d) Производные цифры (атрибуты → здоровье, броня → снижение физ. урона) сдвигаются без своей строки вклада.
4. **Уже исправлено?** Нет (wip = 0.17.5, код выше).
5. **Сервер** не затронут; формы данных нет - только клиент (core + app).
6. **Варианты.**
   - **A (рекоменд.)** Вклады боя считать дельтами по группам источников, «телескопом»: тело под картой → +эффекты → +заряды →
     +силы → +условия → +низкое здоровье → +ауры врагов; вклад группы = `figures(после) − figures(до)` той же цифры, в той же
     единице, что строка (процент защиты, действующее под пределом). Сумма по построению = итог. Нужен в `FightHud` срез строк по
     группам (из `heroLines()`), пересчёт `model.body` на группу - только при открытом листе и смене эффектов. Внутри группы
     «Эффекты» - разбивка по эффекту тем же телескопом. ~5-6 ч.
   - B. Дешевле: оставить фразы, но добавить строку «Прочее в бою: ±N» = итог − база − карта − известные дельты. Сумма бьётся, но
     «Прочее» неинформативно. ~2 ч.
   - C. Убрать вклады боя, оставить только «было → стало» + кнопку разбора. ~0,5 ч, теряем информацию.
7. **Крайние случаи.** Ауры врагов меняются по ходу боя (умерший враг снимает ауру) - пересчёт по снимку; MORE/INCREASED -
   порядок групп влияет на раздел долей (не на сумму) - зафиксировать порядок; цифры с пределом (сопротивления у 75%) - вклад сверх
   предела показывать «(сверх предела)»; бой арены стоит, пока лист открыт (`ArenaHold`) - пересчёт не гонится со снимком; офлайн не
   влияет. Тестировщик/админ - то же.
8. **Тексты.** Группы: «Заряды» / «Заряды выносливости»; «Силы уникальных вещей» / «Силы вещей»; «Условия боя» / «Пока держится
   условие»; «Ауры врагов» / «Ауры противников»; «Низкое здоровье». Сверх предела: «сверх предела» / «не действует: предел 75%».
9. **Макет** не нужен (та же строка-сумма). Размер: A ~5-6 ч, вместе с #571/#570 ~7 ч.
10. **Вопросы:** вариант A или B? Показывать вклад сверх предела отдельно или резать до предела?
11. **Связи:** #571 и #570 - тот же блок, делать вместе; #577 частично (видимость строк закона).
