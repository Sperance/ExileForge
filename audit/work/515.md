## Вопросы и ответы
1. Свита босса с плашкой — да (рек.) / нет. Ответ: да; без плашки только боссы.
2. Цвет — по редкости врага (рек.) / нейтральный / по разнице с героем. Ответ: по редкости.
3. Место — правый нижний угол (рек.) / левый нижний. Ответ: правый нижний.
