# #335 Портал выхода после босса - подтверждение удержанием
Пакет: D; статус: решено; сервер: нет; дизайн: да (лист)
## Разбор
core/run/ExpeditionWorld.kt:438 при мёртвом страже касание exitReach сразу WorldEvent.Exit → RunWalk.kt:69 → exit() :110-115 CLEARED. Есть ConfirmSheet(holdMillis=Hold.CONFIRM_MS), шаблон hud.fountain + StepOff/TakeFountain, portalArmed :425-431.
Варианты: A (рек.) ядро exitArmed/hud.exitOffer/TakeExit/StepOff + ConfirmSheet с удержанием «Завершить карту?» и строкой «Останется», пауза через HoldsRun, перевзвод после выхода из радиуса; B только VM - хрупко. 2-3 ч.
## Вопросы и ответы
1. Мир при открытом листе? Ответ: на паузе (HoldsRun).
2. Что подтверждать? Ответ: финальный портал И выход из зоны Ваал.
3. Строка «Останется: …»? Ответ: да, если что-то осталось.
4. Тексты листа? Ответ: короче, без поясняющей фразы: «Завершить карту?» + «Останется: …» + удержание «Завершить»; Ваал - «Вернуться на карту?». Ключи *_note удалить.
Ревью: авто-выход после стража Ваал (RunCommands.kt:127) убрать - по решению владельца выход из зоны Ваал тоже подтверждается.

## Решение
Ядро: флаг взвода выхода (по образцу portalArmed) и предложение в hud, команды «принять/отойти»; отказ - герой отходит, лист снова только после выхода из радиуса. Клиент: стандартный ConfirmSheet с удержанием (Hold.CONFIRM_MS) «Завершить карту?» / для Ваал - свой текст, строка «Останется: …» при остатках. Без сервера. Макет не делаем: стандартный лист подтверждения.
