## 3.82.0

- Обновления теперь скачиваются с сервера игры, а не с GitHub: быстрее, работает там, где GitHub недоступен, и прерванная загрузка докачивается. Проверка версии больше не задерживает запуск.
- Окно «Запуск игры» показывает под каждым активным пунктом его шаги с временем — видно, на чём остановилась загрузка. Добавлен пункт «Вход». Если запуск идёт дольше 15 секунд, можно продолжить, не дожидаясь.
- Если игра зависнет, при следующем запуске отчёт о зависании сам уйдёт разработчику.
- Убран «Путь изгнанника» (плашка с заданиями сверху).
