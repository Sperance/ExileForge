## Разбор

## Вопросы и ответы
1. Разведка врага — в лист врага по тапу (рек.) / мини-строкой над журналом / на карточке. Ответ: в лист по тапу.
2. Строка стаи — тонкой строкой над журналом (рек.) / на карточке вожака / над рядом врагов. Ответ: над журналом; ярость — значком на карточке врага.
3. Боссы — тот же принцип (рек.) / не трогать. Ответ: тот же принцип (рамка босса как есть, разведка в лист, журнал в центре и на паузе).
4. Страж — правило + снимок экрана (рек.) / только правило. Ответ: пункт RULES «Бой на арене» + снимок боя с 1, 4 врагами и боссом в KeyScreensShotTest.
5. Пустой журнал — «Коснитесь врага, чтобы узнать о нём» (рек.) / «Бой ещё не начался» / «Журнал появится с первым ударом». Ответ: рекомендованный.
6. Строка стаи — «Волна 2/3 · осталось 4» (рек.) / «Раунд 2 из 3 · врагов: 4» / «2/3 · 4 врага». Ответ: рекомендованный; без волн — «осталось 4».

## Решение
PackHeader и ScoutPanel убрать с арены; всё о враге — в FoeCard (имя, плашка уровня #515, редкость рамкой, Мощь, печати, полосы, полка эффектов, значок ярости); центр — всегда FightFeed с подсказкой до боя; разведка — в FoeSheet по тапу; строка стаи над журналом. Боссы — тот же принцип. Правило в RULES + снимки в KeyScreensShotTest. Макет: ждёт (вместе с #514, #515, #512).
