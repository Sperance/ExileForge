# #283 Отчёты игроков - сделать просмотр информативнее (макеты)
Пакет: Админка; статус: ждёт макет; сервер: да; дизайн: да

## Разбор
Суть: модератор решает по новому отчёту вслепую.
Где: клиент `app/.../screens/server/AdminFeedback.kt` (FeedbackAdminPage :59, ReportLine :157, AdminTicket :195, AuthorLine :272), `core/.../model/feedback/Feedback.kt:113-140`; сервер `BugReport.kt:112-170,235 (toModeration),359,374`, `FeedbackService.kt:162`.
Причина: `toModeration` режет системное (версия, устройство, context, failures, crashes, trail, heroSheet, sentAt) - «всё в Issue», а у нового отчёта Issue ещё нет. Клиент не показывает и то, что приходит: versions, dislikes, номер Issue в строке, роль, screen.
Варианты: 1) всё в FullReport; 2) лёгкая строка + `admin/feedback/detail?id=` (рекомендация); 3) только клиент из имеющегося.
Макеты: A плотный список + секции-досье; B конвейер решений по одному; C лента-таймлайн.
Сервер: API_REVISION, RULES.md:99, KDoc; вайп не нужен.
Размер: 5-7 ч (+2-3 для B/C).
Вопросы: поля строки; показывать журнал/сеть/стеки/героя/устройство модерации?; фильтры/сортировки; новые действия (дубль, шаблоны отказа, досье автора, копировать журнал); направление; подгрузка при раскрытии.

## Вопросы и ответы
1. Что показывать модерации? Варианты: всё, что идёт в Issue (рекомендовал) / версия+падения+ошибки / только уже приходящее.
   Ответ: всё, что идёт в Issue: версия, устройство и среда, журнал действий, ошибки запросов, падения (с версиями), снимок героя, время отправки - свёрнутыми секциями.
2. Загрузка? Варианты: при раскрытии (рекомендовал) / всё в списке.
   Ответ: при раскрытии; в списке - счётчики падений и ошибок.
3. Фильтры/сортировки? Варианты: «с падениями», версия клиента, «Повторы», раздел игры (мультивыбор).
   Ответ: только фильтр по версии клиента.
4. Новые действия? Варианты: досье автора, копировать техническое, «Дубль #N», шаблоны отказа (мультивыбор).
   Ответ: только переход в досье автора.
5. Строка списка? Варианты: версия, бейджи падений/ошибок, номер Issue и +/−, класс/ур. (мультивыбор).
   Ответ: версия, бейджи падений и ошибок, номер Issue и «+/−».
