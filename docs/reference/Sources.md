`Contract.kt` клиента закрепляет именно этот серверный коммит и версию 1.74.6. Версия Android-клиента — 3.80.31. Wiki самостоятельна: она описывает выбранные ветки, но не меняет default branch и не является релизом приложения.

Приоритет источников: действующий код расчёта и проверок → типизированная модель и значения по умолчанию → JSON-контент → локализованный текст. Исторические разделы README не использовались как источник текущих количеств и лимитов.

Каталоги сохраняют все сущности из файлов `equipment`, `items`, `modifiers`, `stats`, `powers`, `tree`, `atlas`, `skills`, `campaign`, `pets` и `tables`. Дополнительные страницы параметров сохраняют явные настройки, рецепты, задания и другие вложенные данные. Это разные представления данных: перечень полей JSON не является готовым расчётом боя.

## Как трактовать справочники <a href="#как-трактовать-справочники" id="как-трактовать-справочники"></a>

* Уровень базы, требование к уровню героя и уровень экземпляра — разные величины.
* Числа уровня 1 → 20 в умениях — границы масштабирования, а не случайный диапазон.
* Числа min → max в роллах предмета — диапазон случайного свойства.
* Нулевой вес исключает запись; отсутствие поля может означать значение Kotlin по умолчанию.
* Локаль иногда содержит исторический текст. В спорных случаях пояснение руководства опирается на исполняемую проверку, например сундуки можно выставлять на аукцион, хотя старый комментарий модели говорит иначе.
* Наличие поля или определения в каталоге не гарантирует, что оно используется конкретным предметом или открыто данному герою.

## Обновление <a href="#обновление" id="обновление"></a>

Для нового среза нужно обновить оба исходных коммита, сверить закрепление сервера клиентом, пересобрать каталоги, проверить изменения формул и ограничений, затем проверить внутренние ссылки и числа. Изменение локали само по себе не доказывает изменение механики.

В этой работе проверены структура, содержание и ссылки документации. Игровой клиент и сервер не запускались; опубликованная версия сервера отдельно не проверялась.
