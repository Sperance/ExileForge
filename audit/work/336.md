# #336 [Идея] Вернуть надевание лута в походе
Пакет: H Улучшения; статус: ждёт макет; сервер: да; дизайн: да
## Разбор
История: до 3.90.1 «Подходящее» в Снаряжении, «Надеть» в луте/сундуках/итогах, RunCommand.Regear с pendingGear. Убрано c8ee55ba (view-only during runs and trials, сервер CH_036); b66d210c снял CH_036 - запрет только в клиенте, InventoryService.equip :94 пускает.
Лут: бой на клиенте; добычу катит сервер на событие журнала (CampaignService.events → apply); прибавки к добыче замораживаются на входе (context() CampaignService.kt:249 → RunState.context); сундуки на входе (RunStart.chestStock); Plausibility.Pace по текущей экипировке в БД.
Нужно: 1 сервер - лутовый контекст на Engage, событие Regear, правило добычи (мин. по наборам), API_REVISION, RULES_VERSION, Run.boost, поле RunState с умолчанием (без вайпа) 5-7 ч; 2 клиент между боями (вернуть по c8ee55ba), новая фляга 0 зарядов 4-6 ч; 3 горячая замена в бою 10-14 ч (риск детерминизма); 4 разбор добычи в итогах 2-3 ч. Всего 21-30 ч.
Абуз: MF-набор на старте → боевой; перезапуск «на старте»/«раз на бой»; фляги; бесплатная смена на паузе; Pace по набору на момент отправки; сундуки.
## Вопросы и ответы
1. Лут при переодевании? Ответ: переодеваться можно только вне боя - посреди боя ничего менять нельзя (этап 3 «горячая замена» отпадает).
2. Цена в бою? Ответ: только между боями.
3. Оружие посреди боя? Ответ: посреди боя вообще ничего нельзя менять.
4. Здоровье/щит при смене максимума? Ответ: сохранить число, урезать по максимуму.
5. Какие вещи? Ответ: только найденные в этом заходе.
6. Где? Ответ: только поход по карте (Испытания, Разлом, Башня - набор фиксирован на входе).
7. Неоткрытые сундуки после смены набора? Ответ: пересчитывать (с текущим набором на момент открытия).
8. Силы «в начале боя»/«раз за карту»? Ответ: «в начале боя» - со следующего боя; «раз за карту» - не повторно при снятии/надевании.
Из Issue: смена любой фляги - новая фляга с 0 зарядов; временные эффекты снятой вещи остаются до конца срока, постоянные - снимаются сразу.
## Решение
Сервер: прибавки к добыче пересчитываются на начале каждого боя (Engage) и при открытии сундука по текущему набору (лутовая часть контекста отдельно от той, что задаёт монстров/объекты карты - спавны клиента и сервера не расходятся); событие журнала «Regear» (между боями, только вещи, найденные в этом заходе); API_REVISION, RULES_VERSION, поле RunState с умолчанием (без вайпа). Клиент: «Надеть» в луте/итогах/сундуках и вкладка подходящего в снаряжении во время похода по карте, только вне боя; фляга 0 зарядов; эффекты - как выше; итог боя показывает добычу с учётом набора. Проверка правдоподобия (Plausibility.Pace) - по набору на момент боя, не на момент отправки журнала.
