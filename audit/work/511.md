# #511 [Баг] Полностью вырежи механику Отдыха вне боя. вся регенерация должна происходить сама
Пакет: 1 Поход: правила захода; статус: решено

## Разбор
См. audit/work/triage/expedition.md (раздел #511).

## Вопросы и ответы
1. «Регенерация сама» — варианты: 1%/с сразу как реген (рек.) / только реген листа / базовый реген всем и в бою. Ответ: только реген листа (предупреждён: начало игры тяжелее).
2. Под ранящим недугом — варианты: как сейчас, восстановление стоит (рек.) / реген всегда. Ответ: как сейчас.

## Решение
Отдых вне боя удалить целиком: offCombatRegen/restDelay из контента и правил (с default для старых клиентов), код отдыха RoadLife, разбор LifeFlow rest/restIn, строки EffectShelf, ключи fight.flow.rest/fight.flow.part.rest на всех языках, пункты RULES.md. На карте — только регенерация листа; ранящий недуг её останавливает, как сейчас. Механику «отдыха» Разлома не трогать.
