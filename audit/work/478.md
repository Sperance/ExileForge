# #478 Боссы разлома недели слабые - уникальнее, с навыками/дебафами
Пакет: 2 Разлом недели; статус: решено; сервер: да (контент + новые эффекты); дизайн: нет
Числа урона - в #462.

## Разбор
3 стража без фаз, по 1 навыку; у боссов кампании фазы у 149/166.

## Вопросы и ответы
1. Как: готовые фазы + 1 свой дебафф (рек.) / только готовые / полностью свои. Ответ: готовые фазы + 1 свой дебафф.
2. Дебаффы: разные по теме (рек.) / один общий. Ответ: разные по теме.

## Решение
Страж Врат: фазы QUAKE + MOB_WARCRY, дебафф «Печать врат» -15% скорости атаки, слои до 3, 8 с.
Поглотитель: HEXER (уязвимость, слабость) + MOB_MANA_DRAIN, «Истощение» -20% лечения и вампиризма, 8 с.
Владыка: STORM + MOB_VULNERABILITY, «Разлом стихий» -15 ко всем сопротивлениям, 8 с.
Локаль новых эффектов ru/en сервер+клиент. Closes #478.
