# Сферы, эссенции, знамения и крафт

## Перед применением <a href="#перед-применением" id="перед-применением"></a>

Проверьте цель, редкость, уровень экземпляра и свободные места аффиксов. Осквернённые и зеркальные экземпляры не принимают обычные операции сфер. Валюта и изменение предмета подтверждаются совместно; отказ проверки не должен расходовать валюту. Некоторые операции предлагают выбор — следующая сфера отменяет старые невыбранные варианты.

## Базовые сферы <a href="#базовые-сферы" id="базовые-сферы"></a>

| Сфера | Действие над обычной экипировкой | Важное ограничение |
| --- | --- | --- |
| Превращения | Обычный → волшебный | Нужна обычная вещь |
| Улучшения | Добавляет аффикс волшебному | Нужно доступное место и подходящий модификатор |
| Изменения | Перебрасывает волшебные аффиксы | Закреплённые сохраняются |
| Алхимии | Обычный → редкий | Стандартный ролл ниже максимума аффиксов на один |
| Царская | Волшебный → редкий, добавление и нормализация | Итог должен соблюдать минимум редкости |
| Хаоса | Перебрасывает редкие аффиксы | Знамение стороны может сохранить другую сторону |
| Высшая | Добавляет аффикс редкому | Ограничена местами и пулом |
| Божественная | Перебрасывает значения допустимых свойств | Без знамения тира не меняет тир |
| Священная | Перебрасывает имплиситы | Нужен подходящий имплисит |
| Аннулирования | Удаляет подходящий аффикс | После операции действуют правила допустимой редкости |
| Очищения | Убирает изменяемые аффиксы | Для карты отдельное поведение |
| Удачи | Преобразование по правилам редкости | Уникальный исход зависит от допустимого пула |
| Ваал | Осквернение и один из исходов | После порчи дальнейшие сферы недоступны |
| Зеркало Каландры | Создаёт зеркальную копию | Не универсальная операция для любой цели |
| Закрепления | Закрепляет аффикс | Минимум 4 аффикса по правилу |
| Раскрытия | Предлагает скрытый аффикс | Требуется последующий выбор |
| Качества | Повышает качество | Эффект зависит от слота и катализатора |
| Сожаления | Возврат узлов | Не применяется к вещи как обычный крафт |

Полный текст каждой сферы и её торговое имя: [валюты](Items/Items-CURRENCY.md). Для границ применимости используйте конкретное описание, а не только краткую таблицу выше.

## Карты — особая цель <a href="#карты--особая-цель" id="карты--особая-цель"></a>

Алхимия на карте добавляет алхимическую строку; это не превращение белой брони в редкую. Очищение делает карту волшебной с одним случайным аффиксом, сохраняя закреплённое. Карта не должна стать пустой обычной. Божественная со знамением тира повышает допустимые тиры аффиксов карты, тогда как на обычной экипировке выбирается один подходящий аффикс.

## Знамения <a href="#знамения" id="знамения"></a>

Знамение тратится вместе с совместимой сферой и меняет её действие: выбор из вариантов, работа с определённой стороной аффиксов, усиленное добавление, изменение тира, гарантированный вариант порчи или вид качества. Несовместимая пара отклоняется.

Знамение выбора позволяет решить, какое свойство принять из предложенных, но не позволяет самостоятельно написать любое свойство или выбрать тир вне уровня вещи. Точные варианты: [знамения](Items/Items-OMEN.md).

## Эссенции <a href="#эссенции" id="эссенции"></a>

Обычная вещь становится редкой с гарантированным свойством. Свойство зависит от вида цели: оружие, оружие заклинателя, колчан, броня или украшение. Часть высоких ступеней и особые эссенции могут перебрасывать уже редкую вещь. Волшебная вещь, уникальная, фляга, карта и самоцвет не проходят обычную проверку эссенции.

Сначала определяется гарантированная строка. Сохранённые строки и группы исключения ограничивают оставшийся ролл. Закреплённый аффикс той же группы уступает гарантии; конфликт с постоянным имплиситом приводит к отказу. Сила гарантии связана со ступенью эссенции и допустимым уровнем вещи.

В контенте **8 ступеней**, **20 обычных видов**, **4 особых вида**. Конденсация использует **3 входных эссенции**, базово **300 секунд**; уровни открытия ступеней задаются в [параметрах эссенций](reference/Parameters-essences.md).

## Верстак и ремесленные свойства <a href="#верстак-и-ремесленные-свойства" id="верстак-и-ремесленные-свойства"></a>

Верстак использует варианты CRAFTED семейства модификатора. Допустимые слоты, тиры и цена задаются отдельно. Нельзя считать crafted обычным природным аффиксом с тем же диапазоном. Снять ремесло можно по правилу очищения верстака.

Ремёсла могут добавлять HANDCRAFTED-свойства. Базовая вероятность — **20%**, максимум таких строк — **3**, максимум добавок — **2**; для карт отдельная вероятность **25%**. Пул уникальных результатов кузницы и обычных результатов различается. Полные рецепты: [профессии](Professions.md).

## Практическая последовательность <a href="#практическая-последовательность" id="практическая-последовательность"></a>

Сначала выберите подходящую базу и уровень предмета. Определите, нужен ли гарантированный эффект эссенции, влияние или особый источник. Затем работайте с редкостью и аффиксами; до дорогой операции проверьте заполнение сторон и группы исключения. Порчу и создание зеркальной копии рассматривайте после обычных улучшений, потому что они закрывают последующие операции.
