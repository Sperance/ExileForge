## 1. Фактический порядок расчёта удара (проверено кодом)

**Лист (rules, одинаков у клиента и сервера)** - `SheetCalculator.hero` (`rules/sheet/Sheet.kt:220-295`):
1. База: `critical.sheetBase` + база класса по уровню; без оружия - `unarmedBase` крита.
2. Операции: строки класса, узлы дерева (с гнёздами), законы тронов (`ThroneLaws.heroLines`), строки дара Предначертания.
3. Экипировка: вещь сворачивается локально (`foldItem`: база вещи + локальные прибавки × локальные увеличения, качество, катализатор) в одну прибавку; набор работающих вещей - неподвижная точка требований (`activeSet`).
4. Свод на характеристику по порядку реестра: `(база + ΣADD) × (1 + ΣINC/100) × Π(1 + MORE/100)`, SET последним, **округление до десятых** (`ModifierMath.apply`, `Sheet.kt:86-95`); конверсии `perStat` - от уже посчитанного источника.
5. Силы уникалок над листом (`Powers.applySheet`, тоже `tenths` на каждом шаге); затем счёт надетого и силы слотов (пересвод).
6. Предначертание: при `STOCK_FATE_EFFECT > 0` лист считается второй раз с выросшими строками, затем `reshape`.
7. `HeroBody`: + строки пассивных умений (ауры × `STOCK_AURA_EFFECT`) поверх свода (`fold.with`). В забеге `HeroBuild.body` (`Loadout.kt:210-230`): строки Разлома + пассивные + строки момента → свод → доли карты/Атласа (`MapEffects.hero`).

**Боец** (`Combatant.kt`): чтение с капами - скорость атаки `0,3..5`, крит `≤ ceilings.critical (70..90)`, блок/блок чар `≤75`, уклонение `≤75`, физика (броня+снижение вместе) `≤90`, сопротивления `[-50; 75..90]`, скорость чар `≤300`, восстановление умений `0,1..2,5`; ауры врагов - `under()`.

**Удар** (`BattleStrikes.kt:25-178`):
1. Цель неуязвима → BLOCKED, 0.
2. Броски: уклонение (меткость против уклонения, `≤evasionCap`, только не-чары) → блок (блок чар для чар) → крит (свой у чар; «удачный» - второй бросок); замороженная цель не уклоняется и не блокирует; «Без критов» Разлома и оберег дара гасят крит.
3. Множители: крит `max(1, мульт × keener + critTaken)` или `nonCritMore`; двойной урон; «против состояния» (увеличение рядом с увеличениями удара, `versus`); `eased` (подавление/отклонение - бросок) × Укрепление (`DamageTaken.hits`) × Скверна; против недугов/проклятия.
4. Конверсия: случайная стихия, «как доп. урон», физика цели «как стихия».
5. По видам: разброс × множитель × против × `damageMore` × двойной × versus × дар → «Тяжкие удары» → + запас «Зеркала» → броня (физика: `a/(a+5·raw)` под потолком вместе со снижением; стихии - доля брони) → сопротивление (пробивание, пол −50) → `≥0` → × «получаемый урон» (`DamageTaken.of`, пол 0,1) × шок × `eased` × шкалы накопления → печати → закон.
6. Приземление (`BattleLand.kt:26-139`): Каменная кожа дара → барьер → щит (хаос мимо) → мана перед здоровьем → отложенная доля → здоровье; лёд колется; возврат (recoup); добивание; вампиризм `× recoveryRate × Recovery.share(LIFE)` под потолком 20% max/с (у монстра ещё подавление и потолок 1,5%/с); здоровье за удар оружием × `recoveryRate` (без `Recovery`); мана: вампиризм и за удар × `share(MANA)`; выжигание маны; шкалы/оглушение; недуги (от урона **после** защит); журнал; отклики героя (проклятие флягой, Укрепление, заряд фляг за крит, пассивные `≤2` уровня вложенности, силы с флагом `busy`); отклики на удар по герою; свойства монстров; дар.
7. Смерть: `fell()` один раз на врага (`fallenOrder`): здоровье/мана/щит за убийство, баффы, заряды фляг по редкости, отклики KILL, силы, «последние слова», дар. Затем шипы/отражение, если атакующий жив.
8. Шаг (`BattleTick.kt:30`): регенерация (`Recovery.share`, `lifeFromMana`, `recoveryRate`, потолок монстра), щит, мана (`Recovery.manaRegen`), глотки фляг (без `Recovery`) → деген, отложенный урон → недуги → строка `LIFE_FLOW` → истечения → дар → ярость → Разлом → силы → фляги → умения → умения монстров → замахи по очереди `nextAttack`.
9. Награда: `ExpeditionRun.fell` → `RunEvent.Kill(pack, member)` → ответ сервера (дедупликация убийств на сервере - зона отчётов 04/09, здесь не проверялась).

## [COMBAT-01] Силы «лечение от урона» обходят Recovery и потолок вампиризма

## [COMBAT-02] NaN физического смягчения при нулевом ударе и нулевой броне

- **Категория:** BUG (устойчивость). **P3.** **Уверенность:** высокая для механизма; достижимость на текущем контенте не подтверждена.
- **Файлы:строки:** `combat/Combatant.kt:133` (`armour / (armour + factor × raw)` = 0/0), `combat/BattleStrikes.kt:102-112` (нет проверки `raw ≤ 0`, в отличие от `elementalArmour` `:190`), `combat/BattleViews.kt:111` (`event.damage.roundToInt()`), `combat/BattleRift.kt:251` (`min(max, life + NaN)`).
- **Инвариант/ожидание:** `DamageTaken`: «никакая стопка строк не делает бойца неуязвимым» (и, по смыслу, ничто не убивает «пустым» ударом); удар `≥ 0` (`coerceAtLeast(0.0)` в коде - NaN его проходит).
- **Факт** (тест `nan_when_raw_physical_is_zero_and_armour_zero`):
  ```
  physicalMitigation(raw=0, armour=0) = NaN
  hero DAMAGE −100 → foe life=NaN alive=false outcome=LOSS t=0.35  (event ATTACK HIT dmg=NaN)
  strikes() -> IllegalArgumentException: Cannot round NaN value.
  monster DAMAGE −100 vs hero armour 0 → hero life=NaN outcome=LOSS t=0.55
  ```
  NaN убивает цель (`life > 0` ложно), вампиризм `min(NaN, …)` = NaN убивает атакующего; экран ударов падает.
- **Условие:** множитель удара = 0: `damageMore` (`STOCK_DAMAGE ≤ −100`, у героя - сумма `AURA_WEAKEN` живых врагов ≥100), `nonCritMore` (`NON_CRIT_DAMAGE ≤ −100`). На контенте найдено: `AURA_WEAKEN` до 25 на враге (3 врага на поле - 75; бой босса со свитой и тотемами - больше трёх), `NON_CRIT_DAMAGE` −40 (одна уникалка), Ослабление −35% × эффект проклятий. Сборки, дающей ровно 0, не найдено - не проверено перебором.
- **Варианты:** (а) в `physicalMitigation` вернуть 0 при `raw ≤ 0` (как у стихий); (б) фильтровать типы с `raw ≤ 0` до защит; (в) общий страж конечности урона в `land` (`isFinite`).
- **Регрессионный тест:** удар с множителем 0 по цели без брони - урон 0, оба живы.
- **Рекомендация:** (а)+(в) - дёшево. **Статус:** открыто.

- **Побочные эффекты:** пересчёт сохранённой Мощи (сервер пересчитывает по отпечатку контента - ок), изменение доски славы.
- **Регрессионный тест:** `Might.hero` не меняется от `CAST_SPEED`, если в слотах нет заклинаний.
- **Статус:** открыто.
