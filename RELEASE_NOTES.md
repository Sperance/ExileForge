## 3.76.0

- Сундуки: новый вид добычи — 12 тематических сундуков. Падают с боссов и финалов регионов, из Испытаний и в награду за задания. Лежат в сумке в отдельном разделе «Сундуки», открываются бесплатно; продать на аукционе нельзя.
- 14 новых классовых уникальных предметов — по два на каждый класс. Выпасть могут любому, но надеть может только герой своего класса.
- Карты: модификаторы «больше добычи» убраны. Количество и редкость добычи теперь растут от вредных модификаторов — чем выше их тир, тем богаче награда.
- Разделы открываются с уровнем героя: закрытые отмечены замком и подписью, с какого уровня доступны; при открытии нового раздела — уведомление.
- Дерево навыков: узлы стали заметнее — неоновое свечение по цвету типа, доступные для взятия мягко пульсируют.
- Вкладка «Поход» больше не подвисает при нажатии.
- Проверка обновлений: приложение ждёт её завершения, при ошибке — кнопка «Повторить»; при возвращении в игру проверка запускается снова.
- Отчёт об ошибке стал проще: отправляется только ваш текст.
