## Расширение: ловушки на картах (владелец, тем же пакетом)
Вопросы и ответы:
1. Форма: своя у каждого вида (рекомендовал) / любая у любого / круг. Ответ: своя по виду (шипы - линия 3-5 клеток поперёк прохода, огонь - пятно 2×2/3×3, яд - облако-круг); награды за ловушки убрать.
2. Новые виды: лёд и молния (рекомендовал) / оставить 3 / + подвижные. Ответ: лёд, молния и подвижные.
3. Подвижные: жернов (рекомендовал) / маятник / оба / пульсирующие. Ответ: все три - жернов (катится по прямой 4-6 клеток, бьёт при касании и отбрасывает), маятник (дуга вокруг точки), пульсирующие зоны (включаются и гаснут по таймеру).
4. Сколько: 2-4 с ростом от тира (рекомендовал) / 2-5 / 4-8. Ответ: 4-8.
5. Монстров ранят: да (рекомендовал) / только героя. Ответ: только героя, как сейчас (монстров - только с силой уникалки, maxStrike).
6. Урон: растёт с тиром, ниже нынешнего на низких (рекомендовал). Ответ: да; одним срабатыванием не убивает.
7. Видимость: видны + вспышка ~0.5 с перед ударом (рекомендовал). Ответ: да.
8. Повтор: удар при входе + перезарядка (рекомендовал) / бьёт, пока стоишь / раз за карту. Ответ: бьёт, пока стоишь (раз в 1-2 с, пока герой в зоне).
9. Награда: ATLAS_TRAP_REWARD и POWER_TRAP_SPOILS - переделать в защиту «ловушки ранят меньше на N%» (рекомендовал). Ответ: да.
10. Отрисовка: 3 макета. Ответ: 3 макета + в пул модов карт мод «Больше ловушек».
11. Мод «Больше ловушек»: вредный, +50-100% ловушек, повышает количество/редкость добычи захода (рекомендовал). Ответ: да.
12. Стихии: жернов - физ. + отброс, маятник - кровотечение, пульсирующая зона - случайная стихия (огонь/лёд/молния/яд) (рекомендовал). Ответ: да.
Следствия без вопросов: стражи TRAP_WARD_COLD/LIGHTNING для новых стихий; RULES_VERSION; правила «Поход»/ловушки в RULES обоих репо. Делать после пакета 2 (тот правит features.traps по #320).
13. Отрисовка (320-traps.html): В + свечение из А + колесо/маятник из Б (рекомендовал) / А / Б / В. Ответ: Б «Механизмы» - у каждого вида своя плита (дыры шипов, решётка с жаром, вентиляция яда, иней - крест, медная шина и столбы молнии - цепь из 4 клеток, пульсирующая зона - ромб со сменой стихии), при ударе из пола встают шипы/огонь/иглы, жернов - каменное колесо в жёлобе, маятник - лезвие на столбе.
14. Ритм: всегда своим ритмом, видно заранее (рекомендовал). Ответ: да.
Новые ключи: названия 8 видов, подсказка «<стихия> · <эффект> · урон», «Бьёт раз в N с, пока стоишь в зоне».
