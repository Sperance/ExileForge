## #447 Аукцион: выкуп растёт пропорционально ставке
- **Суть:** k = выкуп/первая ставка; после ставки S выкуп = ⌈S·k⌉ (10/30 → ставка 11 → выкуп 33).
- **Где:** `backend/rules/.../rules/trade/Bidding.kt:102-127` (`minBid` режет по `maxPrice`, `bid` — ставка ≥ выкупа = выкуп, `buyout` по `maxPrice`); `backend/src/.../logic/trade/AuctionService.kt:248` (bid), `:291-296` (выкуп по `lot.price`); `backend/src/.../data/auction/AuctionSearch.kt:49` (фильтр витрины по полю `price` в Mongo). Клиент: `BidSheet`/`BidRow` (`ui/screens/auction/AuctionBids.kt`) печатают `lot.price`.
- **Как сейчас:** выкуп = `lot.price`, неизменен весь срок; `BidState.minPrice` хранит первую ставку. Не сделано.
- **Сервер:** да (правила + сервис), клиент — почти без правок, если сервер сам кладёт новый выкуп в `lot.price`.
- **Варианты:**
  1. *(рекоменд.)* В `BidState` новое поле `listed` (выкуп при выставлении, 0 у старых → берётся `price`); на каждой ставке `lot.price = ⌈amount·listed/minPrice⌉` той же транзакцией. Плюсы: фильтр/сортировка витрины по `price`, сбор `AuctionFees.buyer`, клиент — всё работает «само». Минусы: правка `Bidding.bid` + тест исхода.
  2. Выкуп только вычисляемый (`Bidding.buyoutAt(state, price)`) без записи. Плюсы: формы данных не трогает. Минусы: фильтр «цена до N» и сортировка в Mongo видят старый выкуп; клиенту тоже надо считать.
  3. Не пропорционально, а «выкуп ≥ ставка + шаг·N» — мягче, но не то, что просили.
- **Нюансы:** при k=1 первая ставка = выкуп (как сейчас); плата за место берётся по выкупу при выставлении — не пересчитывается; шкала `BidSheet` «первая ставка → выкуп» поедет — подпись «выкуп растёт со ставкой ×k» в ⓘ правил торгов; ставка ≥ выкупа (выкуп-ставкой) при k>1 больше не случится — оставить только кнопку «Выкупить».
- **Макет:** нет (подпись в ⓘ). **Размер:** 4–6 ч (сервер 3, клиент 1, тесты `Bidding`).
- **Вопросы:** (а) округление вверх/вниз/до шага? (б) потолок выкупа (например ×10 от исходного) или без потолка? (в) применять к уже идущим торгам или только к новым лотам? (г) показывать покупателю «выкуп вырос с 30 до 33»?
- **Формы данных:** +1 поле в `AuctionLot.bidding` с умолчанием — аддитивно, без вайпа и без подъёма версии `CollectionSchemas` (AuctionLot v1).
