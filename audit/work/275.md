# #275 Админ не может сменить Предначертание другим игрокам
Пакет: Админка; статус: готово; сервер: да; дизайн: нет

## Разбор
Суть: в чужом досье нет кнопки смены дара.
Причина: так задумано (решение по #35, `audit/decisions-0.15.0.md:31`; сервер RULES.md:73 «админ своему аккаунту… без цели»). Сервер `AdminRoute.kt:68` `post("/fate")` без цели, `FateService.kt:64-79` только `actor._id`, `ModerationPolicy.kt:87` `canRedrawOwnFate`. Клиент `AdminClient.kt:44`, `ModerationModel.kt:205`, `Dossier.kt:214` (кнопка только своему), лист `Dossier.kt:380` `FateRedrawSheet`.
Не исправлено.
Варианты: 1) цель в `admin/fate` + `ModerationPolicy.canRedrawFate` + `DossierRights.fate`, кнопка по праву (рекомендация); 2) сбросить выбор, игрок выбирает сам; 3) отдельный маршрут с причиной и письмом.
Сервер: API_REVISION 91→92, правки обоих RULES.md, AuthTest; вайп не нужен.
Размер: 3-4 ч.
Вопросы: прогресс дара сбрасывать?; назначать или сброс выбора?; письмо игроку/причина?; кто может (ADMIN/MODERATOR, чужой админ нельзя), лимит?; начатый заход?

## Вопросы и ответы
1. Действие? Варианты: назначить любой дар (рекомендовал) / сбросить выбор / оба.
   Ответ: назначить любой дар (тот же лист из 29).
2. Счётчики дара? Варианты: с нуля, как себе (рекомендовал) / сохранять.
   Ответ: с нуля.
3. Игроку и журналу? Варианты: письмо + причина в журнал (рекомендовал) / только журнал / причина без письма.
   Ответ: обязательная причина в листе, запись в журнал модерации, письмо игроку «Администрация сменила ваше Предначертание на …: <причина>».
4. Права? Варианты: только админ, кроме других админов (рекомендовал) / админ и модератор.
   Ответ: только ADMIN, чужого админа нельзя; без лимита; начатый заход доигрывает со старым даром.

## Решение
Сервер: цель (герой/аккаунт) и причина в admin/fate (без цели - себе, как сейчас), ModerationPolicy.canRedrawFate, DossierRights.fate, письмо игроку (ключи локали сервера на всех языках). Клиент: кнопка в любом досье по праву, поле причины в FateRedrawSheet. Правки RULES.md обоих (строки про «только себе»), audit/decisions. Вайпа нет.
