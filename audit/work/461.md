# #461 После боя в разломе журнал итогов сам закрывается
Пакет: 2 Разлом недели; статус: решено; сервер: нет; дизайн: нет

## Разбор
Плашка «Победа» живёт только пока итог боя летит на сервер; затем арена снимается вместе с открытым журналом (RiftActions.kt:303-317, RiftScreen.kt:1205-1256, 1334). Лист итога - только у стражей (RiftActions.kt:250).

## Вопросы и ответы
1. Когда: после каждого боя (рек.) / + выключатель / только элита. Ответ: после каждого боя.
2. Вид: тот же лист, что у стража (рек.) / новый. Ответ: тот же лист.

## Решение
Лист итога стража - для любого выигранного боя Разлома, закрывается только касанием «Дальше». Closes #461.
