Новые механики боя — 5 макетов

Всё на привычной арене: карточки врагов сверху, герой снизу, ряд кнопок. Каждая механика ложится поверх автобоя: игрок вмешивается коротким нажатием, а без него бой идёт как раньше. Анимации зациклены.

Как работает: два разных состояния на враге дают реакцию: поджог + шок = Перегрузка (взрыв по всем), холод + шок = Раскол (крит по замёрзшему), поджог + холод = Пар (ослепление), яд + поджог = Чума (яд перекидывается). Награда за смешение стихий в навыках и экипировке.
