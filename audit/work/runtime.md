# Проверки рантайма (обзор exileforge-runtime.md): решения владельца
Статус: вопросы; идут в 0.17.0 (решение владельца). Сервер: да; клиент: да.

## Ответы
- Куда: в 0.17.0.
- S1 один кеш сессии и один хеш токена на запрос: да.
- S2 TTL кеша сессии: 5 минут (проверить evictUser при бане/выходе/смене пароля/роли).
- S3 идемпотентность: claim в памяти (TTL 1 ч) + Mongo-журнал для рестарта; KeepReport не парсить готовый ответ (байты data до конверта).
- S4 кеш манифеста по роли: да.
- S5 [HTTP]: не писать только скучные (hero/view → 304, health, статика).
- S6 encodeDefaults=false, explicitNulls=false: да, в 0.17.0 (прогнать живой контракт client-server).
- S7-S9 запись героя: все три (один отпечаток на цикл, флаг вместо третьего BSON, lazy имена полей).
