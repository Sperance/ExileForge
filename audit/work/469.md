# #469 Новый предмет «Лист Угнетения» - сменить имя текущего героя; выдаёт только админ
Пакет: 7 Новые предметы и права; статус: сделано; сервер: да; дизайн: да (диалог ввода имени)

## Разбор
Расходники: items.json (Item, rules/content/Equipment.kt:289, флаг bound), локаль name/description/trade, иконка icons.json (IconsTest). Общего «использовать» нет. POST /hero/grant/item открыт и тестировщику себе (AccessPolicy.kt:89-92). Имя - копиями: лоты, состав и журнал гильдии, почта, чёрный список, Maker («сделано мной» по имени), возврат стопок гильдии по имени. Проверка имени в HeroService.create (:87-95).

## Вопросы и ответы
1. Старое имя: освободить сразу, живые копии обновить, история как была, в досье «Бывшие имена» (рек.) / резерв 7 дней. Ответ: освободить сразу.
2. Свойства: привязан, без ограничения частоты (рек.). Ответ: да.
3. Выдача: только админ, общий признак grant: ADMIN (рек.). Ответ: да.

## Решение
Общий маршрут использования стопки (/hero/bag/use, use: RENAME_HERO), признак выдачи ADMIN в контенте и AccessPolicy; проверка имени вынесена из HeroService.create в общий валидатор; переименование под блокировкой героя в одной транзакции с обновлением живых копий (лоты, состав гильдии, чёрный список, Maker, рекорды, возврат стопок - переход на id где можно); история (письма, журнал) не трогается; досье - бывшие имена. Иконка, локаль ru/en. Клиент: «Использовать» в листе стопки -> диалог ввода имени (общий с #468). Closes #469.
