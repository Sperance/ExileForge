# Проверка Exile Forge

GitHub Actions выполняет `:core:test`, `:app:lintDebug`, `:app:assembleDebug`, `:app:assembleDebugAndroidTest`
и `:app:assembleRelease` (R8 не должен выкинуть сериализаторы). Затем эмулятор Android 35 запускает
UI-тесты и сохраняет снимки экранов.

С 2.54.0 остались только критически важные тесты (решение владельца); с 3.0.0 они идут против модуля `rules` сервера:

- `UiStringsTest` — словарь клиента `ui_{ru,en}.json` и `ui_common.json`: одинаковые наборы ключей,
  нет пустых строк, плейсхолдеры не теряются, каждый `ui("...")` из исходников есть в словаре,
  каждое значение перечислений `rules`, которое показывает клиент, названо, каждый стат реестра
  подписан — в словаре клиента или в словаре сервера.
- `ContentSmokeTest` — контент закреплённого сервера (подмодуль `backend/`) читается модулем
  `rules`: лист каждого класса стоит, заход по семени катается одинаково дважды, волшебная и редкая
  вещь не выходит из ролла пустой, журнал захода переживает перезапуск.
- `ServerIntegrationTest` — только в задании `client-server`: сервер собирается из подмодуля,
  изолированный MongoDB и настоящий `GameApi` против живого сервера — манифест и чанки, снимок героя,
  выдача/надевание/сфера/продажа, заход по семени и его журнал, аукцион, промокод, права игрока.
- UI: `DesignPreviewTest` и `HeroPanelTest` снимают `design/arsenal.jpg` и `design/hero.jpg` —
  workflow без этих файлов падает.

Артефакты: `exile-forge-debug` (APK), `exile-forge-ui` (результат UI-тестов и снимки),
`client-server-reports` (отчёты живого теста и лог сервера).
