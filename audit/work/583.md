# #583 Характеристики в бою считаются странно
Пакет: 2 Характеристики в бою; статус: ждёт макет; сервер: нет; дизайн: да

## Разбор
ChangeSources (HeroSummary.kt:293-301), fightParts (StatsSheet.kt:164-174): вклады боя - фразы SkillText.statLine, не числа; показаны только heroEffects (тело героя из BattleTick.kt:256-260: заряды, силы уникалок, условия, низкое здоровье, ауры врагов - без строк); строка печатает действующее (процент защиты, предел 75%), «Герой без похода»/«Итог» - сырое.

## Вопросы и ответы
1. Вклады числами по группам телескопом (рек.) / фразы + «Прочее» / только было→стало. Ответ: числами по группам.
2. Сверх предела - отдельной строкой «Сверх предела» (рек.) / резать. Ответ: отдельной строкой.
3. Названия групп: Заряды / Силы вещей / Условия боя / Ауры врагов / Низкое здоровье (рек.). Ответ: эти; эффекты - по имени каждого.
4. Макет - да.

## Решение
Разбор: Герой без похода → +Карта → +эффекты (по каждому) → +Заряды → +Силы вещей → +Условия боя → +Низкое здоровье → +Ауры врагов → «Сверх предела: −N». Вклад = дельта той же цифры в единице строки, сумма = число строки. Без «Итог» (#571). Подписи - #570.
