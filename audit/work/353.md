# #353 Контракт «войти в зоны 13» дал почти уровень
Пакет: Задания; статус: решено; сервер: да; дизайн: нет
## Разбор
Цель RUNS (quests.json:80) засчитывается на входе (CampaignService.kt:262, TrialService.kt:126). Опыт = опыт уровня x min(5% x scale, 60%) (Quests.kt:159, QuestEngine.kt:185): уникальный контракт = 60% уровня. Дёшевы также SELL, SPEND/EARN, AUCTION_BUY, ORBS, LEVEL.
Варианты: а) засчитывать RUNS по завершении захода с условием; б) вес награды цели в quests.json (RUNS 0,25...); в) снизить общий потолок. Рек. а+б. 1,5-3,5 ч; без вайпа.

## Вопросы и ответы
1. Засчёт «Войти в зоны»? Ответ: заход засчитывается, только если он с картой (заход по карте) и в нём выигран хотя бы 1 бой; в тексте всех заданий на заходы написать, что заход - только с картой.
2. Вес награды? Ответ: поле веса награды цели (по умолчанию 1): заходы 0,5, торговля (продать, потратить/заработать золото, купить лот, сферы) 0,5.
3. Потолок 60%? Ответ: оставить.

## Решение
quests.json: вес награды цели, RUNS -> засчёт на итоге захода по карте с >=1 победой (CampaignService.kt:262, TrialService.kt:126 - пересмотреть), тексты целей ru/en «с картой». Quests.experience/QuestEngine.reward - множитель веса. RULES_VERSION (98), уже выданные задания - старая награда.
