# #288 Админ: метка enhancement у своих отчётов
Пакет: 3 Багрепорты и модерация; статус: в работе; сервер: да; дизайн: нет (существующие PillTabs)
## Разбор
Клиент BugReport.kt:96 вид жёстко FeedbackKind.BUG, отправка :126, флаг game.isAdmin есть (Banner.kt:76). Сервер BugReportRequest (BugReport.kt:448-468) без метки, IssueFate.kt:102-106 метки bug+from-game+auto, заголовок «[Баг] » :91-94, ModerationPolicy.kt:77 filesWithoutReview. Вид SUGGESTION убран миграцией ReportsOnly.kt; правило сервера RULES.md:99 «предложений нет» — переписать.
Предложение: А — флаг enhancement в запросе, сервер принимает только от роли filesWithoutReview, хранит в BugReport (поле с умолчанием, без сноса), метки enhancement+from-game, заголовок «[Улучшение]»; переключатель Ошибка/Улучшение в BugSheet у админа. Тесты IssueFateTest, политика.
## Вопросы и ответы
1. Метки: enhancement + from-game (рекомендовал) / + bug. Ответ: enhancement + from-game.
2. Заголовок: «[Улучшение]» (рекомендовал) / «[Идея]» / без префикса. Ответ: «[Идея] …».
3. Роль: только администратор (рекомендовал) / и модератор. Ответ: только администратор.
4. Вид выбора: две таблетки «Ошибка | Улучшение» сверху листа, PillTabs, общий черновик (рекомендовал) / 3 макета. Ответ: таблетки.
## Решение
Сервер: необязательное поле запроса (enhancement/вид Issue) с умолчанием; принимается только от администратора (правило в ModerationPolicy, от прочих игнорируется), хранится в BugReport (поле с умолчанием, без сноса), Issue получает метки enhancement + from-game (без bug, без auto) и заголовок «[Идея] …». Клиент: у администратора в BugSheet сверху PillTabs «Ошибка | Улучшение», черновик общий. Ключи ru/en. Правило сервера RULES.md:99 («предложений нет…») переписать: улучшение может подать только администратор. Тест IssueFateTest (метки/заголовок) и политика.
