# #298 Счёт дара Предначертания на главной
Пакет: 5 Внешний вид; статус: ждёт макет; сервер: нет; дизайн: да
## Разбор
(пересмотрено) Счёт дара: дар копит на листе героя (лента FateRibbon, подпись «что дар копит»; RULES клиента «Облик ленты дара»). Нужно вынести этот счёт компактно на главную.
(старое, отменено) «Предзнаменования» = «Знамения» (категория OMEN, 13 шт., items.json сервера), стопки сумки (HeroView.bag, hero.count), тратятся в кузнице (ForgeBench.kt:138), в сумке смешаны со сферами (BagPanel.kt:81). Шапка HeroLine.kt:39-48 показывает только золото.
Предложение: чип «✧ N» рядом с золотом в HeroLine → поповер со списком; плюс раздел «Знамения» в сумке.
## Вопросы и ответы
1. Какая валюта (Знамения / вся валюта / другое)? Ответ: «не понял вопроса» → переспросил с примерами названий: Знамения (рекомендовал) / сферы+знамения / только сферы. Ответ: Знамения.
2. Где показывать: шапка у золота (рекомендовал) / страница «Герой» / все в макетах. Ответ: без предпочтения → три места в макетах.
3. Пусто (0): скрывать (рекомендовал) / показывать 0. Ответ: без предпочтения → скрывать.
4. Раздел «Знамения» в сумке: да (рекомендовал) / нет. Ответ: без предпочтения → да.
5. Макет 298-omens.html (знамения). Ответ владельца: «не понял — нужно количество валюты для предзнаменований (например у Трофейщика): у некоторых даров свой подсчёт чего угодно, это должно быть где-то отображено компактно». ⇒ Предзнаменования = дары Предначертания; знамения и раздел в сумке ОТМЕНЕНЫ. Нужен компактный показ счёта дара (трофеи Трофейщика, бои до сферы у Щедрости судьбы, Разгон и т.п.) на главной; новый макет.
