# #284 Поход: кэшировать загрузку, перерисовывать только узлы
Пакет: Поход; статус: разбор; сервер: нет; дизайн: нет

## Разбор
Суть: при каждом входе во вкладку «Поход» - пауза и карта появляется разом.
Причина: `app/.../expedition/ExpeditionScreen.kt` - `settled` в `remember`, `LaunchedEffect` + `delay(TAB_SHIFT_MS=220)`, до этого `CHART_BARE`; `drawn = chart?.takeIf { settled }` прячет даже готовую кэшированную карту (`WorldChart.last`, `WorldArt.cache`, `LocalWorldArtLayer`). Слои `world/WorldCanvas.kt:39-124` (5-6 холстов) рисуются заново. `ui/TabNavigation.kt:95-127` хранит только rememberSaveable. Ожидание добавлено ради плавной смены вкладки (808a4ef7, 3780cc11, dae8f54b; v0.16.3). Сеть не виновата.
Варианты: A) при готовом кэше рисовать сразу, ожидание - только первая сборка (1 ч); Б) неподвижный слой (пергамент, туман, дороги) в GraphicsLayer, отдельно - узлы, анимация, надписи (3-4 ч); В) держать вкладку в композиции (4-6 ч, риск).
Рекомендация: A+Б.
Вопросы: объём; допустим ли рывок анимации смены вкладки.
