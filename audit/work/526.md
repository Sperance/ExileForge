# #526 [Баг] Что за ошибка "Сервер не застал бой со стаей"? Вырежи эту механику проверки полностью
Пакет: 1 Поход: правила захода; статус: решено

## Разбор
См. audit/work/triage/expedition.md (раздел #526).

## Вопросы и ответы
1. Проверка убийств — варианты: найти и починить (рек.) / вырезать полностью / только спрятать тост. Ответ: вырезать полностью (предупреждён о риске фарма).
2. Тост отказа в заходе — варианты: только админу и тестеру (рек.) / всем / никому. Ответ: только админу и тестеру, для всех видов отказа.
3. Текст тоста — варианты: с причиной по коду правила (рек.) / «Часть боя не засчитана» / «Сервер не принял убийство — добыча не выдана». Ответ: с причиной.
4. Повтор уже засчитанного убийства — варианты: молча без награды (рек.) / вырезать и это. Ответ: вырезать и это (предупреждён: повтор снова катит добычу).
5. Нет жетона/монстра на сервере — варианты: искать жетон везде (Ваал, основная карта, призванные; непроснувшийся считать проснувшимся; не нашёл — принять без добычи и в лог) (рек.) / добыча по уровню зоны. Ответ: искать жетон везде.

## Решение
Сервер: событие KILL больше не отказывается ни по одному правилу (повтор, Ваал без зоны, жетон не проснулся, нет монстра). Монстр ищется в Ваал, на основной карте и среди призванных; непроснувшийся жетон считается проснувшимся; не нашёлся — убийство принято без добычи, причина в лог сервера. Повтор убийства катит добычу снова (решение владельца).
Клиент: тост отказа сервера в заходе (все виды) — только админу и тестировщику, текст с причиной по коду правила (тексты причин - на всех языках).
