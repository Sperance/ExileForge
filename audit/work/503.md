# #503 [Баг] так же окно выкупа чуть переделай, это должно быть все отдельное окно, без двойных прокруток списков, только с одной пр…
Пакет: 6 Торговля; статус: ждёт макет

## Разбор
См. audit/work/triage/city.md (раздел #503).

## Вопросы и ответы
1. Окно — отдельная страница «Рынок › Аукцион › Лот» (рек.) / лист без подвала. Ответ: страница с одной прокруткой: товар → статус и срок → шкала → лента ставок → продавец → блок ставки в самом низу.
2. Закреплено — только две кнопки «Ставка N» / «Выкупить за M» (рек.) / ничего. Ответ: две кнопки.
3. Охват — все лоты одним видом (рек.): у лота за цену только «Купить», у своего — просмотр и «Снять». Ответ: да.
4. Тексты — «Лот» / «Ваша ставка» (рек.). Ответ: да.

## Решение
BidSheet/LotSheet/OwnBidSheet → одна страница-уровень TrailLevel «Рынок › Аукцион › Лот» с одной verticalScroll; блок ставки (степпер, мин. ставка и шаг, залог, «выкуп станет N», сбор) последним; закреплены только две кнопки. Правило RULES.md:79 (закреплённый подвал) переписать. Макет: ждёт.
