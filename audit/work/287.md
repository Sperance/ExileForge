1. Охват: акты 2–9 + Бездна, 44 босса (рекомендовал) / все кроме Разлома / акт 1 с ур.5 + 2–9 + Бездна / только 2–9. Ответ: акты 2–9 + Бездна (акт 1 и стражи Разлома не трогаем).

3. Список «босс → фаза»: по теме на моё усмотрение (рекомендовал) / таблица на правку / равномерно по видам. Ответ: по теме на моё усмотрение; итог - в dev-notes Issue и сообщении коммита.
