# Срез добычи за разницу уровней (новое правило, без Issue)
Статус: в работе; сервер: да; клиент: да (строка на шторке стража); дизайн: нет

## Разбор
Опыт уже режется окном (`rules.json experienceWindow`), монстры растут вслед за героем (`heroScale`, льгота 6), лут - нет. Все пути босса сходятся в `Run.boss` (Run.kt:852-874) → `grant`; обычные - `Run.kill`, стражи - `corrupt`/`crystal`, Бездна `hoard`. Множители - `Run.boost` (Run.kt:1163-1172).

## Вопросы и ответы
1. Кривая? A (рекомендовал) льгота 6, −5%/уровень, линейно / B льгота 3, −10% / C льгота 10, −3%. Ответ: A
2. Пол? A (рекомендовал) 25% / B 10% / C 50%. Ответ: A
3. Охват? вещи+золото+сферы; шансы уникалок/мифика; книга/рецепт/руна/карта; обычные монстры и стражи. Ответ: ВСЁ
4. Версия и показ? A (рекомендовал) 0.17.0, строка «добыча −X%» на шторке стража / B без показа / C 0.16.12. Ответ: A

## Решение
`campaign.json` → `lootFalloff {grace 6, perLevel 5, floor 25}` (уровень campaign, рядом с heroScale), `LootFalloffRule.share(heroLevel, areaLevel)`; доля в одной точке `Run.boost`/`grant` для всех источников лута монстров (kill, boss, corrupt, crystal, hoard) - количество, золото, сферы, шансы уникалок/мифика, книга/рецепт/руна/карта. Опыт не трогаем. Клиент: строка на шторке стража (`GuardianSheet`), когда доля < 1. Версия пакета → 0.17.0.
