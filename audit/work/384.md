# #384 Мод «Монстры возвращают здоровьем % урона» непонятен
Пакет: Испытания и забег; статус: решено; сервер: да (локаль); дизайн: нет

## Разбор
Мод карты MAP_MONSTER_LEECH (вампиризм монстров), locale/ru.json:4782, modifiers.json:13673; механика работает (MapEffects.kt:83 -> LEECH_ALL, BattleLand.kt:68-69). Ни у одного из 70 статов MAP_* нет stat.desc; пояснения под строкой только для Атласа (Text.kt:204-210 atlasLineNote).
Варианты: A описания всех MAP_* + показ под модом карты (4-5 ч); B переписать один шаблон (15 мин); C ⓘ со статьёй «Моды карт».

## Вопросы и ответы
1. Как объясняем моды карт. Варианты: пояснения всем 70 серой строкой (рекомендовал) / переписать тексты / только этот. Ответ: переписать тексты.
2. Где пояснение. Варианты: серой строкой (рекомендовал) / по касанию. Ответ: по касанию строки.
3. Уточнение: и переписать, и пояснение по касанию? Ответ: оба.

## Решение
Пройти все 70 статов MAP_*: непонятные шаблоны переписать (ru/en, сервер), добавить каждому короткое пояснение stat.desc.MAP_* (ru/en, сервер + клиент по правилу словарей), показывать его по касанию строки мода карты. Тексты для игрока - таблицей владельцу на одобрение до коммита.
