# #463 Нельзя выйти из разлома и потом вернуться
Пакет: 2 Разлом недели; статус: решено; сервер: да; дизайн: нет (окно подтверждения - общий компонент)

## Разбор
«Назад» закрывает экран, забег ждёт всю неделю (RiftActions.kt:146-151, RiftScreen.kt:450). Дыра: снаряжение берётся заново на каждый бой (ExpeditionActions.kt:640), сервер не запрещает смену в Разломе (InventoryService.kt:112-119).

## Вопросы и ответы
1. Выход: «Назад» с подтверждением удержанием (рек.) / + автоконец 2 ч / любой уход. Ответ: «Назад» с подтверждением; закрытие приложения/обрыв - не выход, при запуске сразу открывается Разлом.
2. Запрет: снаряжение, древо и умения (рек.) / только снаряжение / ничего. Ответ: снаряжение, древо и умения.

## Решение
Клиент: «Назад»/«Покинуть» -> подтверждение удержанием -> завершение забега; при запуске с открытым забегом - сразу Разлом. Сервер: отказ смены снаряжения, древа и умений при открытом забеге (новый код ошибки + локаль ru/en). Closes #463.
