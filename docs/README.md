## Как пользоваться

Верхняя строка разделов служит навигацией между страницами; слева — общее меню. В каталогах сначала идёт указатель, затем карточки. Код сущности позволяет найти её независимо от языка интерфейса. Для длинного каталога используйте поиск браузера.

В описаниях различаются **шаблон** предмета, **конкретный экземпляр** и **итоговая характеристика героя**. Диапазон в карточке не обещает максимальный ролл. Вес в таблице не равен проценту выпадения. Каталоги отражают этот срез контента, а не состояние конкретного запущенного сервера.

Русские описания сохранены из игровой локализации, торговые названия вещей — из общего словаря. Это документация реализации ExileForge: сходство названий с Path of Exile не означает одинаковые правила.
