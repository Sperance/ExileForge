# #396 Вибрация не работает
Пакет: Отчёты и мелочи; статус: решено; сервер: нет; дизайн: нет

## Разбор
Причины: buzzButtons по умолчанию false (core/app/Settings.kt:25); ForgeApp.kt:104-108 view.performHapticFeedback(VIRTUAL_KEY) подчиняется системному виброотклику (на vivo часто выключен, с API 33 обойти флагом нельзя), VIRTUAL_KEY очень слабый; нет пробной вибрации. Buttons.kt:434 и RunBagSheet.kt:87 идут в обход настроек Buzzes.
Предложение: свой Haptics на Vibrator/VibrationEffect + разрешение VIBRATE, все вызовы через Buzzes, пробная вибрация при включении. 2-3 ч.

## Вопросы и ответы
1. Работать при выключенном системном виброотклике. Ответ: да, свой Vibrator + VIBRATE (рекомендовал).
2. Кнопки и ремесло по умолчанию. Ответ: включена (сохранённые настройки не трогаем) (рекомендовал).
3. Пробная вибрация. Ответ: при включении переключателя (рекомендовал).
4. Сила. Ответ: кнопки/ремесло - короткий клик, опасность - двойной тяжёлый (рекомендовал).

## Решение
Свой Haptics на Vibrator/VibratorManager + VibrationEffect (EFFECT_CLICK / двойной тяжёлый, с откатом createOneShot/waveform для старых API), разрешение VIBRATE, атрибуты USAGE_TOUCH. Все вызовы (в т.ч. Buttons.kt:434 удержание и RunBagSheet.kt:87) - через Buzzes и настройки игры. buzzButtons по умолчанию true. Пробная вибрация при включении переключателя.
