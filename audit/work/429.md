# #429 [Баг] Так же автор багрепорта должен уметь Закрывать свой багрепорт кнопкой, со статусов Новый и Обсуждение
Пакет: Отчёты; статус: ждёт макет; сервер: да, API_REVISION; дизайн: лёгкий

## Разбор
Причина: Автор умеет только удалить (canDeleteReport); статуса закрытия нет.
Предложение: Статус WITHDRAWN, POST bugreport/close, кнопка. 4-6 ч, вместе с #428.

## Вопросы и ответы
1. Закрыть и Удалить? Варианты: статус + Удалить остаётся (рек.) / статус, Удалить убрать / переименовать. Ответ: статус «Закрыт автором», кнопку Удалить у автора убрать - отчёты стирает срок.
2. Подтверждение и возврат? Ответ: удержание, без возврата; писать в закрытом нельзя.
3. Где у модерации? Ответ: в «Закрыто» с пометкой «Закрыт автором», стирается сроком отклонённых.

## Решение
BugStatus.WITHDRAWN из CREATED и DISCUSSION; POST bugreport/close; удалить авторское удаление (маршрут bugreport/delete, canDeleteReport, кнопка, ключи - grep по обоим репо); purgeClosed по sentAt; API_REVISION вместе с #428.
