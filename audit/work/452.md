# #452 Красные (ключевые) узлы дерева навыков - добавить слабую сторону
Пакет: 3 Поход и бой; статус: решено; сервер: да (контент tree.json + разовый сброс); дизайн: нет

## Разбор
31 ключевой узел (tree.json), таблица - triage/maps.md. Без минуса или с мнимым: SHA_K7, TEM_K7 (нет), WIT_K7, MAR_K5, RAN_K0, RAN_K6 (минус по ненужной классу защите). RAN_K5+RAN_K0 = +100% больше уклонения.

## Вопросы и ответы
1. Минусы: по теме (рек.) / везде -N% здоровья / по всем 31. Ответ: по теме.
2. RAN_K5 +60%->+45% (рек.) / оставить. Ответ: срезать до +45%.
3. Взятые узлы: бесплатный сброс + письмо (рек.) / только письмо / ничего. Ответ: сброс + письмо.

## Решение
SHA_K7: -20 сопр. хаосу, -8% здоровья. TEM_K7: -20 сопр. молнии, -6% скор. атаки. WIT_K7: -12% здоровья. MAR_K5: -10% скор. передвижения, -6% скор. атаки. RAN_K0, RAN_K6: -8% здоровья. RAN_K5: +60%->+45%. Разовый идемпотентный возврат очков за изменённые узлы (TreeService.refund) при старте сервера + письмо (локаль ru/en). Closes #452.
