# #465 Описания всех предметов сумки кратко и понятно (как в PoE)
Пакет: 5 Предметы и баланс; статус: решено; сервер: да (словари + новый ключ); дизайн: нет (InfoMark)

## Разбор
item.<CODE>.description (locale ru/en, LocaleKey.itemDescription rules/text/LocaleKey.kt:61); клиент core/display/Text.kt:62, StackFace BagPanel.kt:197-217. 573 предмета; длинные: сферы 80-421, эссенции 245-443 (дублируют гарантии), оттиски 164-296, руны 98-150 (хвост про гнездо). Таблица и тексты - triage/items.md.

## Вопросы и ответы
1. Подход: два уровня - кратко + «Подробнее» (рек.) / только кратко / только >200. Ответ: два уровня.
2. Лор-фразы: в «Подробнее» (рек.). Ответ: да.
3. Дубли (гарантии эссенций, хвост рун): убрать (рек.). Ответ: убрать.
4. Тексты сфер (22, список в triage/items.md): приняты как есть; сверить с кодом каждой сферы.
5. Эссенции/оттиски/руны/знамения: приняты (эссенция «Делает обычный предмет редким с гарантированным модификатором. Ступень N из 8.», у Воющей/особых «...или перековывает редкий»; оттиски; руна - только эффект; знамения «выбора» и «тира» - одной строкой). Остальное не трогаем.

## Решение
description - короткая строка (<=~90), прежний текст (без дублей гарантий/гнезда) -> новый ключ item.<CODE>.details под InfoMark «Подробнее» в листе стопки; ru и en тем же коммитом; числа только через {r:…}; LocalizationTest на полноту details там, где он есть. Closes #465.
