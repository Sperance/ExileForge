# #454 Запрос о выборе отправлен - окно зависло (Разлом недели)
Пакет: 1 Падения и связь; статус: ждёт макет; сервер: нет; дизайн: да
Связан: #462 (часть «видно, если нет связи») - делается здесь.

## Разбор
Не падение (стек в теле - прежнее падение устройства). Шаг ушёл при обрыве сети; кнопки гаснут до 32 с без спиннера (RiftScreen.kt:937-958, RiftActions.kt:163-197), повторные касания отбрасываются молча, refreshRift() не вызывается, значка связи в полноэкранном Разломе нет (ForgeApp.kt:194).

## Вопросы и ответы
1. Повтор: авто 3 раза, затем кнопка (рек.) / только кнопка / только авто. Ответ: авто 3 раза, затем «Повторить».
2. Охват: общий компонент в ui/components, подключить в Разломе и арене (рек.) / вся игра / только Разлом. Ответ: общий компонент, подключить в Разломе.
3. Сроки: спиннер 1,5 с, плашка 8 с, тайм-аут шага 15 с (рек.) / 0-5-10. Ответ: 1,5 / 8 / 15.

## Решение
Общий индикатор запроса (ui/components): спиннер на нажатой кнопке через 1,5 с, через 8 с плашка «Сервер долго отвечает · Повторить», значок связи в шапке Разлома и на арене; шаг - тот же ключ повтора, 3 авто-повтора, затем кнопка; после восстановления - refreshRift(). Тайм-аут шага 15 с. Макет - 3 варианта.
