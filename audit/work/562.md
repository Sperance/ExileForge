# #562 Квест Бальзамировщика засчитывается любым боссом
Пакет: 1 Квесты и уровни предметов; статус: решено; сервер: да; дизайн: нет

## Разбор
Суть: сюжетные шаги «сразите стража/убейте в зоне X» считаются в любой зоне (32 из 54 шагов).
Причина: QuestEngine.kt:136 (KDoc «счёт идёт в любой зоне»), QuestProgress.advance (rules Quests.kt:474) не знает зону, Hero.count (Hero.kt:283) без зоны. Счёт: CampaignService.kt:533/539/540/572, TrialService.kt:225.
Предложение: Hero.count(counter, amount, zone) → QuestProgress.advance: шаг STORY с place-зоной двигается только в этой зоне.

## Вопросы и ответы
1. Как чиним — по зоне все сюжетные шаги с зоной (рек.) / только шаги на стража / вывод из истории убийств. Ответ: по зоне, все шаги с зоной.
2. Где ещё засчитывать — карта-предмет этой зоны, раш (ступень с этой зоной), Изнанка и Бездна внутри зоны. Ответ: все три.
3. Уже закрытые «не тем» боссом несданные шаги — оставить (рек.) / сбросить. Ответ: оставить.
4. Подсказка в строке шага — «Только в зоне: {зона}» (рек.) / «В других зонах не считается» / без. Ответ: «Только в зоне: {зона}».

## Решение
Сервер: счёт сюжетного шага с зоной только в этой зоне (обычный поход, карта-предмет, раш со ступенью этой зоны, Изнанка/Бездна захода). Старые несданные не трогаем. Клиент: подсказка «Только в зоне: {0}» (ru/en) под шагом с зоной. Тест на advance с зоной не обязателен (не падение/потеря данных).
