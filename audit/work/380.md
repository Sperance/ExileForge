# #380 Перерисовать карту Разлома недели похоже на Поход
Пакет: Разлом недели; статус: решено; сервер: нет; дизайн: да

## Разбор
Сейчас вертикальная лента рядов (RiftAscent.kt:56-64), RULES клиента «Карта Разлома». Поход - изометрия с SceneCamera/IsoGrid.
Варианты: A изометрическая плита с тропами по связям плана, акты-ярусы, IsoGrid без полной камеры (1,5-3 дня); B лента с «землёй»-островами и тропами (1 день); C полная сцена Похода (4-6 дней).
Кандидат в улучшение.

## Вопросы и ответы
1. Что взять из Похода. Ответ: изометрическая плита - узлы объектами на ромбической земле, тропы по связям, акты - ярусы-острова, туман, прокрутка вверх без свободной камеры (рекомендовал).
2. Палитра. Ответ: своя палитра Разлома; уточнение после макета - нынешняя зелёная (#39FF88) с фиолетовым, как во всём Разломе.
3. Движение героя. Ответ: фигурка идёт по тропе к выбранному узлу (рекомендовал).

## Решение
Новая отрисовка карты Разлома (RiftAscent) в изометрии с переиспользованием IsoGrid/проекции Похода, схема RiftPlan сервера без изменений. Правило RULES клиента «Карта Разлома» переписать. Макет mock_380.html (scratchpad), выбран вариант C с правкой: извилистый остров-тропа над пустотой, узлы - объекты вдоль пути с развилками, страж - ворота поперёк тропы между актами; владелец: все блоки (узлы) чуть дальше друг от друга. Палитра - нынешняя зелёная RiftColors (не фиолетово-бирюзовая из макета). Значки наград узлов (#381) над узлами, в тумане нет.
