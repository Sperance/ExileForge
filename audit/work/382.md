# #382 Однотипные списки-выборы с поиском
Пакет: Поиск и выбор; статус: ждёт макет; сервер: нет; дизайн: да

## Разбор
Суть: списки вроде «Порог ранга вкладки» - компактно, однотипно, поиск по названию и подназванию.
Причина: Spinner.kt:30-87 - кнопка во всю ширину + AlertDialog с большим полем поиска даже для 4 вариантов; модель Map<key,title> без подназвания. Вызовы: GuildStash:139, RedemptionScreen:175/185, TesterPages:64-100, AdminFeedback:484/500. Ещё 9 своих пикеров-шторок без поиска (SlotPicker, SkillPicker, RunePicker, ToolPicker, JewelPicker, ScopePicker, ModePicker/ArmsPicker, LanguagePicker).
Предложение: A - ForgePicker вместо Spinner: PickOption(key,title,subtitle,glyph), компактная строка 40dp, нижняя шторка, поиск при >7 вариантах (4-6 ч). C - перевод 9 пикеров на тот же каркас (12-20 ч) - кандидат в улучшение.

## Вопросы и ответы
1. Охват. Варианты: выпадающие + 9 шторок (рекомендовал) / только выпадающие. Ответ: только выпадающие (Spinner).
2. Где выбирать. Ответ: нижняя шторка (рекомендовал).
3. Поиск с какого числа вариантов. Ответ: с 8 (рекомендовал).

## Решение
ForgePicker вместо Spinner: PickOption(key, title, subtitle?), компактная строка-кнопка «Подпись · Значение ▾», выбор в нижней шторке ForgeSheet, поиск (общий компактный) при ≥8 вариантах по title и subtitle. Все вызовы Spinner (GuildStash порог ранга, RedemptionScreen, TesterPages, AdminFeedback) с подназваниями где есть смысл. Вид - по макету (ждёт макет).
