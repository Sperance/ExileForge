# #518 [Баг] Сделай чтобы все фонтаны так же восстанавливали 100% энергощита
Пакет: 1 Поход: правила захода; статус: решено

## Разбор
См. audit/work/triage/expedition.md (раздел #518).

## Вопросы и ответы
1. Сила фонтана — варианты: 100% ЭЩ + здоровье и мана 60% (рек.) / только 100% ЭЩ / 100% всего. Ответ: 100% ЭЩ, здоровье и мана 60%, фляги 40%.
2. Текст — варианты: списком (рек.) / фразой. Ответ: списком «Восстанавливает: здоровье 60%, мана 60%, энергощит 100%, заряды фляг 40%»; герою без ЭЩ строку щита не показывать.

## Решение
FountainRule: поле shield (100, default для старых клиентов), здоровье и мана 40 → 60; drink восстанавливает ЭЩ. Текст fountain.offer списком с числами из правил ({r:…}), на всех языках; строка щита только при ЭЩ > 0. RULES_VERSION не нужен, если фонтан не влияет на ролл (проверить при сведении).
