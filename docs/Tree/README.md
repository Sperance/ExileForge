# Дерево пассивных навыков

## Общее дерево, личный выбор <a href="#общее-дерево-личный-выбор" id="общее-дерево-личный-выбор"></a>

В каталоге **810 узлов**. Все классы используют один граф, но начинают со своего стартового узла. Есть малые и крупные узлы, ключевые узлы, гнёзда, атрибутные варианты и мастерства. Поле `only`, если задано, ограничивает узел указанным стартом класса.

Взять можно доступного соседа уже взятого узла, если хватает очков и выбран требуемый вариант. Мастерство **не открывает путь к следующим соседям**. Узел с вариантами требует явного выбора; набор вариантов не означает одновременное получение всех бонусов.

## Взять путь и сохранить план <a href="#взять-путь-и-сохранить-план" id="взять-путь-и-сохранить-план"></a>

Операция пути ищет кратчайший путь от текущего дерева и оплачивает сумму цен узлов. Мастерства и узлы с выбором не используются как автоматически выбираемые промежуточные точки: их вариант должен решить игрок. Если цель недостижима или очков недостаточно, сервер не сохраняет частично оплаченный путь.

План — отдельный список будущих узлов. При его задании сервер пытается взять доступную часть, на которую хватает очков; последующая выдача наград может продолжить план. Не путайте план с уже работающими бонусами.

## Возврат и изменение вариантов <a href="#возврат-и-изменение-вариантов" id="возврат-и-изменение-вариантов"></a>

* Один узел возвращается за **одну сферу сожаления**, если оставшееся дерево связано со стартом.
* Возврат ветки снимает выбранный узел и всё, что отрывается за ним, по сфере за каждый возвращаемый узел.
* Полный сброс сохраняет старт класса и оплачивает все остальные возвращаемые узлы.
* Самоцветы сначала нужно вынуть из затрагиваемых гнёзд.
* Вариант уже взятого атрибутного узла меняется за **одну сферу хаоса**.
* Мастерство меняет вариант через возврат, а не через операцию смены атрибута.

В сохранении находятся код узла и выбранный вариант. Текущая реализация читает строки из актуального графа; старое описание README о неизменяемом снимке бонусов здесь неприменимо.
