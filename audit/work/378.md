# #378 Нельзя начать следующую ступень испытаний, не пройдя предыдущую
Пакет: Испытания и забег; статус: решено; сервер: да; дизайн: нет

## Разбор
Для игрока уже так: сервер TrialService.kt:99-102 (TR_001), открытие ступени :275; клиент TrialsBoard.kt:206-242. Исключение - тестировщик: ProgressGate.open(hero)=hero.tester снимает проверку, клиент free=game.isTester показывает всё открытым (TrialsBoard.kt:89,150,214) - по RULES клиента «Испытания боссов». Автор отчёта - тестировщик (GR_001 в #383).
Варианты: A wontfix (задумано); B убрать ступени раша из ProgressGate (1-2 ч); C переключатель «все ступени» для тестировщика.

## Вопросы и ответы
1. Что делаем. Варианты: переключатель (рекомендовал) / гейт для всех / wontfix. Ответ: переключатель.
2. Охват. Варианты: всё «свободное» тестировщика через ProgressGate на сервере (рекомендовал) / только ступени. Ответ: всё свободное - выключен = тестировщик играет как игрок везде, сервер тоже не пускает.
3. По умолчанию. Ответ: выключен.

## Решение
Серверный переключатель «Свободный прогресс» тестировщика (по умолчанию выкл.); ProgressGate.open(hero) = tester && включён. Клиент: free = тот же признак из снимка; переключатель в тестерских настройках. Правка RULES обоих репозиториев («Испытания боссов»). Хранение признака - проверить форму данных (CollectionSchemas), поле с умолчанием false не ломает старые документы.
