Дверь и рычаг на карте

Задача Asana «Дверь и рычаг ужасно нарисованы». Сейчас (SceneFeatures.kt:233-298) дверь - плоский прямоугольник с аркой, поставленный «лицом в камеру» в центр стенной клетки входа, а стены (WallRelief, пакет ASANA-01) - изометрический массив со скатом дальней кромки. Дверь не лежит в плоскости стены, торчит из середины массива и пропадает, когда комната открыта; рычаг - плоский постамент с кругом-шестернёй.

ПроекцияisoX=(x−y)·unit, isoY=−(x+y)·unit/2; клетка - ромб 2u×1u, стена выдавлена на wallHeight·unit: залы 1.5–1.7u, пещеры/пустоши 0.9–1.3u.
Дверь сейчасТолько у FeatureKind.VAULT и только закрытая (!spot.opened): 0.78u × ~1.2u, дерево, 2 полосы, тлеющий замок-ромб; иначе - светлая трещина.
Рычаг сейчасКлетка пола spot.lever: постамент 0.52u, шестерня, рукоять; не тронут - тёплый ореол, потянут (opened) - откинут, погас.
Чем рисуемPen: rect, ellipse, circle, line, ring, quad, polyline + Path (как у WallRelief). Все варианты ниже - те же фигуры, без спрайтов.

A
Створки в плоскости стены + рычаг на стене

Дверь лежит на обращённой к камере грани стены: каменные косяки и арка, две створки из досок, кованые полосы и петли, кольца; закрыта - из щели между створками бьёт тёплый свет и ложится полосой на пол. Открыта - створки распахнуты внутрь комнаты, проём светится. Рычаг - на соседней грани стены: железная пластина с прорезью, рукоять вверх (ждёт, тёплый набалдашник) / вниз (потянут, зажглась лампа). + Понятно с первого взгляда, вписано в стену. − Мелкие детали (петли, кольца) теряются при малом масштабе; нужна стена рядом с рычагом.

ФИГУРЫ

  • Проём, арка, створки - Path по точкам грани F(s,t) (≈14 точек арки).
  • Доски, полосы, петли - line между точками грани; кольца - ring.
  • Свет щели - line с альфой + пятно на полу quad.
  • Рычаг - quad пластины, line рукояти, circle набалдашника.

ДЛЯ КОДА

  • Новое: функция грани faceY/faceX(cell, s, t) - какая грань входа смотрит в камеру, берём из соседства клетки пола.
  • Открытая комната рисуется (сейчас opened снимает вход с очереди).
  • Рычаг ставится на стену, если рядом есть грань, иначе - на постамент (B).
B
Решётка-порткулис + рычаг на постаменте

Массивная каменная арка с замковым камнем; в проёме кованая решётка с шипами. Открыто - решётка поднята в свод, видны только зубья, цепи натянуты, проём освещён. Рычаг - каменный постамент на полу (как сейчас, но объёмный куб в изометрии): рукоять откинута назад и тлеет / рванута вперёд, на боку загорается знак. + Самый «подземельный», решётку видно и в мелком масштабе, рычаг стоит где угодно. − Решётка «прозрачна» - комната за ней должна быть темнее, иначе читается хуже; в лесу/пустыне выглядит как крепость.

ФИГУРЫ

  • Решётка - 7 вертикальных и 4 горизонтальных line по грани, шипы - quad; подъём - сдвиг по t + clipPath проёма.
  • Постамент - три Path-грани куба, рукоять - line, знак - polyline.

ДЛЯ КОДА

  • Подъём можно анимировать 0.6 с по progress при открытии.
  • Одна функция drawBox(x, y, w, d, h) пригодится и для сундука/алтаря.
C
Проём с рунной печатью + рычаг-обелиск

Простой арочный проём в стене, закрыт светящейся печатью цвета акцента биома (круг с рунами и пеленой), руна на замковом камне. Открыто - печать рассыпалась, проём тёмный с отсветом. Рычаг - каменный обелиск: ждёт - руна тусклая, вокруг пульсирует круг на полу; активирован - руна и навершие горят, по полу к двери бежит рунная нить. + Меньше всего фигур, хорошо читается в любом масштабе, цвет от палитры биома - подходит всем 30 биомам. − Магия вместо механики - «рычаг» перестаёт быть рычагом (название в тексте поменять на «обелиск»?).

ФИГУРЫ

  • Проём - один Path; печать - круг грани как Path (16 точек) + polyline рун, свечение - тот же путь шире с альфой.
  • Обелиск - 2 грани призмы + пирамидка quad; нить - polyline по полу.

ДЛЯ КОДА

  • Цвет печати - palette.accent; пульс как у нынешнего замка (sin(time·2.4)).
  • Нить к двери - от клетки рычага к клетке входа, уже известны в RoomSpot.
