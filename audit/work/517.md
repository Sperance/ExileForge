# #517 [Баг] Во время боя при нажатии на свой собственный портрет (а лучше кнопочку где-то компактную) должны открываться все текущи…
Пакет: 2 Экран боя; статус: ждёт макет

## Разбор
См. audit/work/triage/battle.md (раздел #517).

## Вопросы и ответы
1. Вход — кнопка в углу карточки героя (рек.) / тап по портрету / оба. Ответ: кнопка.
2. «Везде» — все бои + карта (рек.) / только бои / и город. Ответ: все бои + карта (карта, испытания, Разлом, башня).
3. Вкладка «В бою» — итог + источники по тапу (рек.) / только изменённые / всё развёрнуто. Ответ: итог, изменённые подсвечены, тап — из чего сложилось.
4. Бои без паузы — открывается без паузы (рек.) / не открывается. Ответ: без паузы.

## Решение
StatsSheet: вкладка «В бою» из живого тела fight.heroBody (баффы, дебаффы, фляги, карта); кнопка в углу HeroCard во всех боях; на карте — тот же лист. Пауза — где бой допускает. Макет: ждёт.
