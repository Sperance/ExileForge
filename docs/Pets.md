# Питомцы, инкубатор и разведение

## Два рода питомцев <a href="#два-рода-питомцев" id="два-рода-питомцев"></a>

Боевой питомец участвует в сражении. Танк удерживает врагов, боец наносит урон, поддержка лечит героя. Помощник даёт строки герою: ауры, добыча или ремёсла. В каталоге **64 вида**, включая гибриды.

Боевая основа определяется ролью и стихией, растёт с уровнем и изменяется свойствами. Небоевой помощник не превращается в дополнительного атакующего только от повышения редкости.

## Яйца и инкубация <a href="#яйца-и-инкубация" id="яйца-и-инкубация"></a>

Базовый шанс яйца с редкого монстра — **2%**, с босса — **20%**; количество добычи может его умножать. Биом определяет соответствующее яйцо. Редкость и уровень решаются при закладке яйца, а вид и строки — при завершении по установленным правилам.

Уровень вылупления зависит от уровня героя при закладке и доли **0,5–1,0**, минимум 1. Инкубатор имеет **одно базовое место**, максимум **три** с бонусами. Настроенные границы срока — **5–480 минут**; длительность интерполируется геометрически по оценке уровня и редкости. Сокращение времени ограничено **75%**. Инкубация идёт и без открытого клиента.

Базовые веса редкостей вылупления: обычный 70, волшебный 25, редкий 5. Бонус повышения редкости может изменить конечный результат, поэтому это не универсальная окончательная частота редких питомцев для любой сборки.

## Рост и свойства <a href="#рост-и-свойства" id="рост-и-свойства"></a>

Активные питомцы получают **50% опыта героя** по настройке. Значения строк растут с уровнем: базовая доля прироста — **0,03 за уровень выше первого**. Собственная сфера роста отвечает за уровень; редкость и строки изменяются подходящими сферами ремесла через отдельные правила питомцев.

Базовые диапазоны строк: обычный 0, волшебный 1–2, редкий 3–4. Эти значения отличаются от 4–6 аффиксов редкой экипировки. Качество усиливает строки. После порчи обычные сферы больше не меняют питомца. Ошейник героя передаёт нужные характеристики питомцу.

## Скрещивание <a href="#скрещивание" id="скрещивание"></a>

Нужны два боевых питомца не ниже **20-го уровня** и сфера разведения. При подходящих разных стихиях родителей шанс гибрида — **25%**; иначе результатом становится яйцо биома одного из родителей. Родители устают на **24 часа**.

Гибрид получает две стихии, делит удар между ними поровну и использует усиление листа роли **×1,2**. Роль наследуется от одного из родителей. Обычное яйцо не является альтернативным прямым источником гибрида.
