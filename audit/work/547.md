# #547 Способность не срабатывает на «Врагов 3+»
Пакет: 3 умения; статус: ждёт макет; сервер: да; дизайн: да
## Разбор
SlotCondition (rules content/Skills.kt:60) общий для слотов умений и фляг: READY, FIGHT_START, RARE_OR_BOSS, LIFE_50/35/20, MANA_30 (только фляги), SHIELD_BROKEN, ENEMIES_3, AILING, MANUAL. Очередь слотов строго сверху вниз, casting блокирует (BattleSkills.kt:68-82); бой с 3 врагами ~21%.
## Вопросы и ответы
1. Очередь — условные раньше + подсказка (рек.) / только подсказка / порог 2+. Ответ: условные раньше + подсказка.
2. Текст подсказки — «Умения с условием — первыми, дальше сверху вниз» (рек.). Ответ: он. + НОВАЯ ЗАДАЧА владельца: полностью переделать настройку активаций флаконов в гримуаре: красиво, в стиле игры, компактно, очень настраиваемо; пороги «при N%» с полосой 1-100 вместо фиксированных; макеты.
3. Условия с порогом — Здоровье ≤ N%, Мана ≤ N%, Энергощит ≤ N% (вместо «Щит пробит»), Врагов ≥ N (1-5). Ответ: все + ещё.
4. Те же для умений? — да, одна система (рек.). Ответ: да.
5. Данные героев — перенести разовой задачей (рек.). Ответ: перенести.
6. Ещё условия — Здоровье цели ≤ N%; Через N с от начала боя (0-30, вместо «Начало боя»); Под недугом с выбором видов (горение, холод, шок, яд, кровотечение); Враг редкости не ниже X (любой/волшебный+/редкий+/босс, вместо «Редкий/босс»). Ответ: все.
7. Идеи — Резкий урон ≥ N% за 2 с; Враг готовит умение (каст/фаза); На герое нет эффекта флакона (только фляги). Ответ: эти три (второе условие «И» - нет).
## Решение
Условие слота = вид + параметр (порог/набор). Одна система для фляг и умений; условные слоты проверяются раньше «Как готово». Перенос старых настроек разовой задачей. Макет редактора условия - 3 варианта.
