# #496 [Баг] Проверь подробно механику конвертаций урона, например если взята нода дерева навыков "100% физ урона становится хаосом"…
Пакет: 3 Характеристики и баланс; статус: решено

## Разбор
См. audit/work/triage/battle/items.md (раздел #496).

## Вопросы и ответы
1. Охват — весь физ. урон (рек.) / только атаки. Ответ: только атаки.
2. Сила Ядовитого сердца — 60% (рек.) / 75% / 50%. Ответ: 60% (удар 400: 0/400 → 160 физ / 240 хаос).
3. Небесная кузница и прочие — так же (рек.) / только охват / не трогать. Ответ (с уточнением): оба ключевых перевода — только атаки, 60%.
4. Сумма переводов > 100% — делить пропорционально (рек.) / по порядку. Ответ: пропорционально.

## Решение
SHA_K7 «Ядовитое сердце» и TEM_K7 «Небесная кузница»: 100% → 60%, только физ. урон атак; текст узлов прямо говорит, что силы, шипы и прочее остаются физическими (все языки). Несколько переводов одной стихии-источника с суммой > 100% делятся пропорционально (общий проход Powers converted). RULES_VERSION, симуляция.
