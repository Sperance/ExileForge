# #566 Предмет ур. 31 надевается героем 28 ур.
Пакет: 1; статус: решено; сервер: да; дизайн: нет

## Разбор
«Ур. 31» - уникалка EBBTIDE_SIGNET (requiredLevel=1 в контенте, упала на уровне района 31). Sheet.kt:598/601 `Requirements.level`: у уникалок/мификов требование из шаблона (`!rarity.fixed`); карточка прячет чип требования (`levelNeedApart`, ItemView.kt:315).

## Вопросы и ответы
1. Требование уникалок/мификов - max(шаблон, уровень предмета) (рек.) / уровень уникалки = шаблон / только показ. Ответ: max(шаблон, уровень предмета).
2. Надетые выше уровня героя - остаются, но не действуют (рек.) / снять с письмом / не трогать до переодевания. Ответ: остаются, не действуют.
3. Показ - красный значок на иконке слота + строка в карточке (рек.) / только карточка / + тост. Ответ: значок и строка.
4. Текст строки - «Не действует: нужен уровень героя {N}» (рек.). Ответ: он.

## Решение
rules `Requirements.level`: для всех носимых (кроме инструментов и карт) требование = max(requiredLevel шаблона, уровень предмета), уникалки и мифики включены. Надетые выше уровня героя не снимаются и не действуют; клиент: красный значок уровня на иконке слота и строка «Не действует: нужен уровень героя {N}» в карточке надетой вещи (ru/en). Сфера удачи: уникалка наследует уровень базы - ок. RULES.md: правило требования уровня обновить.
