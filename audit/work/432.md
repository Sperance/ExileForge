# #432 Мод карт «сопротивление всем стихиям» действует на хаос
Пакет: Карты; статус: разбор; сервер: да (без вайпа, RULES_VERSION 100→101); дизайн: нет
## Разбор
core MapEffects.kt:61 resists = все DamageType с resist (вкл. CHAOS), применение :76. Стат MAP_MONSTER_RESIST (stats.json:984, EngineStats.kt:114), мод modifiers.json:13398 (8-12…30-40%), campaign.json риск :10834, башня :11208 (30), MUT_RESILIENT :11374 (20), tables.json:2087,:8872. Локаль ru 4846-4847 прямо называет хаос. Нарушает RULES:59 (хаос у обычных монстров 0-10).
Предложение A: только ELEMENTS + новый MAP_MONSTER_CHAOS_RESIST (меньшая сетка, свой риск/вес, иконка, ru/en). 3-4 ч. Б: просто убрать хаос.
Вопросы: сетка/вес хаос-мода, совместимость; MUT_RESILIENT и башня; MAP_HERO_RESIST/MAX_RESIST.

## Вопросы и ответы
1. Сила хаос-мода монстров? Варианты: половина стихийного (рек.) / как стихийный / треть. Ответ: половина.
2. Вместе со стихийным на одной карте? Ответ: да.
3. MUT_RESILIENT и башня? Варианты: стихии + хаос половиной (рек.) / только стихии / хаос тем же числом. Ответ: стихии + хаос половиной (+10, +15).
4. MAP_HERO_RESIST / MAP_HERO_MAX_RESIST? Варианты: не трогать (рек.) / так же. Ответ: так же - только стихии + отдельные хаос-моды героя.
5. Сила хаос-модов героя? Ответ: половина стихийного.
## Решение
Сервер: MAP_MONSTER_RESIST, MAP_HERO_RESIST, MAP_HERO_MAX_RESIST - только стихии; новые MAP_MONSTER_CHAOS_RESIST, MAP_HERO_CHAOS_RESIST, MAP_HERO_MAX_CHAOS_RESIST (сетки и риск вдвое), MUT_RESILIENT и башня - хаос отдельной строкой вдвое. RULES_VERSION +1. Клиент: MapEffects. Локаль всех языков. Вайп не нужен.
