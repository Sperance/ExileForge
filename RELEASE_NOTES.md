## 3.72.0

- Версия приложения теперь видна внизу экрана входа и в разделе аккаунта («Приложение»).
- Обновления без Google Play: при запуске, каждый час и по кнопке «Проверить обновления» игра сама проверяет новую версию на GitHub и предлагает её, только когда сервер к ней готов.
- Найденное обновление обязательно: окно показывает, что нового во всех пропущенных версиях, скачивает файл, проверяет его подлинность и открывает системную установку. Во время захода или испытания окно ждёт их окончания.
- Если проверить обновления при запуске не удалось, игра просит проверить соединение и повторить.
- При первом обновлении Android попросит разрешить установку приложений из этой игры; если установка не удалась, обновление можно скачать в браузере.
