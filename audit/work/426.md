# #426 [Баг] С чего бы бой прошел не поправилам
Пакет: Бой и Разлом; статус: ждёт макет; сервер: при C/D; дизайн: мелкий

## Разбор
Причина: Удар по неуязвимому стражу (LAST_STAND) пишется как BLOCKED (BattleStrikes.kt:42-44), неуязвимость не видна; target() не обходит неуязвимого; журнал боя не прикладывается к отчёту.
Предложение: A: вид попадания 'неуязвим' + плитка 4-6 ч; B: обход цели RULES_VERSION; C: журнал в отчёт 6-10 ч.

## Вопросы и ответы
1. Показ неуязвимости? Ответ: строка журнала «удар по неуязвимому - без урона» вместо «блокирует», не считать в блоки; плитка «Неуязвим N с» с отсчётом на рамке босса.
2. Герой обходит неуязвимого? Ответ: да - выбор цели обходит неуязвимого, если есть кого бить; RULES_VERSION.
3. Журнал боя в отчёт? Ответ: да - сжатый журнал последнего боя свёрнутым блоком в Issue (без имени героя и личного), новое поле с умолчанием, без вайпа.
4. Последний рубеж 20->45%? Ответ: оставить.

## Решение
Клиент: HitKind для неуязвимого, строка журнала, плитка; rules: target() обходит неуязвимого + RULES_VERSION; сервер+клиент: FightDigest в отчёте и IssueBody. Макет плитки - вместе с макетом боя #412.
