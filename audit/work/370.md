# #370 Разделить гибридные модификаторы
Пакет: Кузница и модификаторы; статус: решено; сервер: да (RULES_VERSION); дизайн: нет
## Разбор
Инструменты: WORK_SPEED_AND_YIELD (tool 300), WORK_<PROF>_MASTERY x7 (500): MINING лишняя+находки, HERBALISM находки+лишняя, WOODCUTTING скорость+лишняя, SMITHING удача+опыт, ALCHEMY опыт+находки, CARTOGRAPHY скорость+удача, ENCHANTING удача+скорость (25-30/15-20). Скрытые: VEILED_WORK_SPEED_AND_SAVE, _YIELD_AND_EXPERIENCE, _FIND_AND_RARITY. Одиночные уже есть: WORK_SPEED, YIELD, LUCK, EXPERIENCE, FIND, MATERIAL_SAVE, CRAFT_RARITY. Группа гибрида своя -> стат сейчас стакается трижды.
Предметы (норма PoE?): SHAPER_INCREASED_DEFENCES, ELDER_CHANCE_TO_POISON_AND_BLEED, ABYSS_* x3, 10 VEILED_*, CURSE_DEFENCES/ATTRIBUTES, BASE_CRITICAL_CHANCE.
Старые вещи: удаление семейства -> reconcile молча снимет строку. Рек.: убрать гибриды инструментов из таблиц, вес одиночным, старые копии оставить. 1-4 ч.

## Вопросы и ответы
1. Гибриды инструментов? Ответ: убрать все 11 из таблиц, их вес - одиночным WORK_*.
2. Старые вещи? Ответ: миграция - гибрид -> главное свойство своим числом (мастерства -> первое свойство 25-30; SPEED_AND_YIELD -> выход; скрытые -> большее число) как одиночный модификатор; если такой одиночный уже есть на вещи - остаётся больший, вторая строка снимается (дно редкости через ItemFactory.hold).
3. Гибриды снаряжения? Ответ: не трогать (норма PoE).

## Решение
Сервер: таблицы без 11 гибридов; миграция CollectionSchemas.TASKS (TaskSchema) по образцу RenamedModifiers, Server-Wipe: no; семейства гибридов после миграции удалить из контента; RULES_VERSION (уже 98 в этой версии); versions.md строка миграции.
