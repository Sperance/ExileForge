# #348 Кнопка GitHub в отчётах - только админ, модераторы, тестеры
Пакет: A; статус: решено; сервер: нет; дизайн: нет
## Разбор
Единственная кнопка «Issue #N ↗» - server/AdminFeedback.kt:288, страница FEEDBACK видна при account.isModerator (SettingsScreen.kt:191), сервер закрывает admin/feedback для персонала (AccessPolicy.kt:37). У игрока ссылки нет (ReportTicket.kt:42). Тестеры не видят (isTester - флаг героя, AccountUi.kt:30).
Варианты: 1 закрыть как уже выполненное; 2 «Issue #N ↗» в ReportTicket при isTester||isModerator (~1 ч); 3 тестерам модерация только чтение (сервер, ~3 ч).
## Вопросы и ответы
1. Что дать тестерам? Варианты: ссылка «Issue #N ↗» в тикете игрока (рек.) / очередь модерации на чтение / ничего. Ответ: ссылка в их отчётах.
## Решение
