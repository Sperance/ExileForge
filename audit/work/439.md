# #439 Окно сюжета открывается при входе в игру
Пакет: Сюжет; статус: разбор; сервер: нет (вместе с #440); дизайн: нет

## Разбор
Вход: POST hero/town → refresh пересчитывает derive-цели (QuestEngine.refresh:68), шаг CLEAR/ORBS_USED/ITEMS_SOLD/CRAFT_MADE становится done вне захода → доска с story.done → StoryAfterHost открывает окно поверх «Героя». Также окно к следующему, ещё не сданному шагу; шаги, сданные сервером в конце захода, своё окно не показывают никогда.
Повтор «уже видел»: storySeen локален (новое устройство/очистка) или окно закрыто не через onDone (уход в заход) - не доказано.
Решение - тот же переход «окно по факту сдачи», см. 440.md.
