# Древо навыков

ExileForge 1.11.0 требует сервер с capability passiveTree для этого экрана. Остальные экраны сохраняют прежний контракт.
В «Герой» или «Поход» нажмите «Древо навыков». Выберите героя из списка и обновите дерево.

Общее дерево содержит 115 узлов: шесть ветвей, 18 крупных узлов и шесть ключевых с ограничениями. Стартовый узел тоже даёт бонус и стоит одно очко. По одному очку за каждый уровень после первого, максимум 99.
Каждый узел приходит со своей иконкой из набора сервера: ключевые и крупные узнаются по виду, малые — по характеристике, которую дают ([набор](ICONS.md)).
Двигайте дерево, масштабируйте жестами или кнопками, выбирайте узел на графе. Для точного и доступного выбора есть список с поиском по названию и характеристике. Золотые узлы изучены, зелёные доступны. Панель показывает каждый бонус, стоимость и причину недоступности.

Путь должен оставаться связан со стартом. Сброс отдельного узла или всего дерева бесплатный, но сервер проверяет зависимости и требования надетой экипировки. Во время боя изменения запрещены. Показанные доступные узлы и характеристики приходят с сервера; клиент не рассчитывает игровые бонусы.

При потерянном ответе исходная команда остаётся в DataStore, отдельно для сервера, аккаунта и героя. «Подтвердить действие» повторяет тот же requestId. После 409 обновите дерево. Смена героя/аккаунта очищает видимое состояние. Сервер хранит собственные узлы каждого героя и общую версию определения в MongoDB.

API и архитектура: ktor-bestgame/docs/PASSIVES.md. Unit, UI и реальный клиент-серверный тест проверяют формат команд, очки, влияние на бой, повторы и доступ.
