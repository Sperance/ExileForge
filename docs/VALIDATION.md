# Проверка версии 1.4

Проверка выполняется workflow Android checks: core unit-тесты HTTP-контракта и редактора, Android lint, debug APK и компиляция Compose instrumented-теста.

Новые проверки: поиск и пагинация каталога, получение точной версии, ссылки вместо embedded-определений, редактирование значений с сохранением версии, авторизация и скрытие секретов, повтор крафта с прежним requestId и Long-версией, контракт выпадения/публикации, пустые ответы 401.

Локальный Gradle в текущем окружении не смог загрузить дистрибутив из-за сетевого ограничения; итоговый результат следует смотреть в GitHub Actions на коммите изменения. Запуск UI-теста на устройстве и обращения к работающему серверу пользователя не выполнялись.

Для рефакторинга добавлены проверки типизированных ссылочных полей, всех маршрутов пагинации, валидации выбранного ID и Compose-сценарий выбора записи со второй страницы. UI-тест компилируется в CI; запуск на устройстве отдельно.
