# Проверка Exile Forge 1.10

GitHub Actions выполняет `:core:test`, `:app:lintDebug`, `:app:assembleDebug`, `:app:assembleDebugAndroidTest`.
Затем Android 35 эмулятор запускает AndroidJUnitRunner; workflow проверяет успешное завершение набора UI-тестов и сохраняет снимок до удаления приложения.

45 unit-тестов охватывают HTTP-контракт, выбор ссылок, версии модификаторов, раздельное отображение шаблона/экземпляра и запасные иконки/названия при отсутствии метаданных. UI-тесты проверяют карточку, выбор со второй страницы, отображение новых эмблем/свойств и переключение языка: `LocalizationTest` рендерит карточку предмета на английском и подтверждает, что русский остаётся языком по умолчанию.

Артефакты: `exile-forge-debug` (APK), `exile-forge-ui` (результат UI-тестов и снимок карточек). Проверка против работающего сервера пользователя отдельно.
