# #436 При открытии сумки сама открывается карточка «Осколок сферы превращения»
Пакет: Сумка; статус: разбор; сервер: нет; дизайн: нет. Дубликаты: #437, #438 (тот же игрок, сессия 07:36-07:38).

## Разбор
Причина: BagPanel.kt:92 `StackCell(...) { onOpen(stack.code) }` - хвостовая лямбда уходит в параметр `badge` (StackCell.kt:57-58: onClick, затем badge), а не в onClick. badge вызывается при каждой отрисовке → onOpen последней ячейки (последняя стопка последней категории = SHARD_TRANSMUTATION у игрока); ячейки не нажимаются (onClick=null). Повтор при каждой перерисовке (hero/view, потягивание) - #438, #437.
Введено: 8b397a94 (#407, 0.17.1).
Тот же дефект: RunBagSheet.kt:162, MapSummary.kt:352, ReportScreen.kt:319 (inspect(Inspect.Stack) в отрисовке). ForgeTray.kt:98 - корректно (onClick= явно).
Предложение: onClick по имени во всех 4 местах + переставить в сигнатуре StackCell onClick последним (badge перед ним), ForgeTray на `badge = {}`. ~0.5 ч.

## Вопросы и ответы
1. Как чинить? Варианты: все 4 места + onClick последним в StackCell (рек.) / только 4 места / только сумка. Ответ: все 4 места + защита.
2. #437, #438 закрыть как duplicate? Ответ: да.

## Решение
onClick по имени в BagPanel, RunBagSheet, MapSummary, ReportScreen; в StackCell onClick последним, badge перед ним; ForgeTray на `badge = {}`. Closes #436.
