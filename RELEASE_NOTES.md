## 4.12.1

- Тестировщик теперь отметка героя, а не аккаунта: её ставит администратор в досье героя. Только герой-тестировщик получает выдачи окна тестирования и проходит замки прогресса; аукцион и склад гильдии ему закрыты.
- Экран санкции показывает вид, срок и причину, которую модератор пишет для игрока; служебные заметки, номер санкции и имя модератора видны только модерации. В форме бана и удаления появилось поле «Причина для игрока».
- Аккаунт с логином и паролем больше нельзя открыть по отпечатку устройства — только паролем.
- Выход из захода, отказ от него, вход в другую зону и простой больше часа посреди начатого боя теперь считаются гибелью.
- Вещь, ушедшая в Осквернение, при переполненном тайнике возвращается в переполнение, а не продаётся торговцу.
- Приз недели Разлома приходит ровно один раз, а сорвавшиеся недели дораздаются позже.
- Сундуки и кристаллы на карте выдают награду только по-честному: номер сундука из этого захода, страж кристалла — в темпе боя.
- Если команду перебила параллельная правка героя (покупка вашего лота, исключение из гильдии), клиент повторяет её сам.
- Техническое: сервер 1.87.2, ревизия API 81.
