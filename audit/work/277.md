# #277 Ремесло: поля, на которые влияет инструмент, кликабельны с разбором
Пакет: Ремёсла; статус: ждёт макет; сервер: да (дар в view); дизайн: да

## Разбор
Суть: игрок не видит, как инструмент меняет цикл/выход/находки.
Где: `CraftsJobs.kt:223` JobSheet, `:316` RecipeFormula (`yieldLabel` :345), `:405-427` JobFigures (цикл «база», в час, исход, опыт - касание открывает общую справку `CraftsGlossary.kt`), `:104` JobRow. Формулы `rules/.../roll/Work.kt` (`WorkBonus.of(index, sheet, tool, guild, fate)`): цикл, ничего×(1−luck), находка, выход 1+yield/100, double/triple/save/free, опыт.
Разбора по источникам нет; заготовки: `core/.../character/ToolVerdict.kt` (WorkMeasure), `ProfessionView.bonus`, `BonusChips`, `ui/components/InfoTip.kt` Tipped/TipCallout.
Попутно: 1) сервер `CraftsService.kt:251` view() строит бонус без дара, досчёт `:387` с даром - показ ≠ факт; 2) опыт в JobView - база (`:285`), без бонусов; 3) удвоение/возврат от инструмента нигде не видны.
Варианты: 1) окно разбора по касанию плитки/ячейки, `WorkBreakdown` в core (рекомендация); 2) свёрнутая полоса «Влияние инструмента»; 3) метка + строка в справке.
Размер: 4-6 ч (+1 ч сервер дар, +1 ч удвоение/возврат).
Вопросы: какие поля; разбор вместо справки или + ссылка; база→источники→итог или без/с инструментом; другие источники; отметка без касания; чинить ли попутные 1-3.

## Вопросы и ответы
1. Что в окне? Варианты: разбор по источникам + ссылка в справку (рекомендовал) / только без→с инструментом.
   Ответ: разбор по источникам (база → уровень, инструмент, древо, гильдия, дар → итог) + «Подробнее» в справку.
2. Какие поля? Варианты: все считаемые (рекомендовал) / только тронутые инструментом.
   Ответ: все: цикл, в час, исход (лишняя/впустую/удвоение/возврат), опыт, выход ×1–N, шанс каждой находки.
3. Метка до касания? Варианты: да, маленькой меткой (рекомендовал) / нет.
   Ответ: да, вид - в макете.
4. Попутные расхождения? Варианты: все три (рекомендовал) / только дар / не трогать.
   Ответ: все три: сервер view() с даром; опыт с бонусами; удвоение/возврат видны.
