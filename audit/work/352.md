# #352 MongoWriteException при отправке письма (опять)
Пакет: A Почта/отчёты; статус: решено; сервер: да; дизайн: нет
## Разбор
BRY_001 с именем класса - только MongoErrors.translate в MongoFactory.attempt (config/MongoErrors.kt:35, MongoFactory.kt:~150), т.е. прямая запись в коллекцию внутри транзакции письма (mail/LetterService.kt:88-95). Кандидат - MailCounterRepository.take (mail/MailCounter.kt:34-44): upsert с $expr по _id, ловит только дубликат ключа. Прошлый фикс eccd88a (создавать коллекции при старте) не помог. Кандидаты: ошибка upsert с $expr/конвейером или WriteConflict 112 без TransientTransactionError.
Варианты: 1 (рек.) переписать take: прочитать в сессии, проверить предел в коде, replaceOne upsert; 2 логирование кода драйвера + обернуть в writing; 3 счётчики вне транзакции. Рек. 1+2. 2-3 ч. Вайп нет.
## Вопросы и ответы
1. Как чиним? Варианты: переписать take + лог кода драйвера (рек.) / сначала лог / счётчик вне транзакции. Ответ: переписать + лог.
2. Тест (два письма подряд, параллельная отправка)? Ответ: да.
## Решение
MailCounterRepository.take: чтение в сессии → проверка предела в коде → replaceOne upsert; MongoErrors.translate пишет в лог код ошибки драйвера; тест на два письма подряд и параллельную отправку. Сервер, без вайпа.
