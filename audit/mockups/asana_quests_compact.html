Компактные задания и контракты

Задача Asana «Компактнее отображай контракты и задания». Сейчас QuestRow (QuestParts.kt) - карточка в 5–7 строк: имя + плашка редкости, описание/«Где: …», условия ◆, полоса 6dp, «7 / 10 · осталось 38 мин», фишки наград, ряд кнопок. Это ~150–190dp на задание, на экран QuestsScreen (360×800, под шапкой, карточкой главы и сегментами «День / Неделя / Контракты») влезает 3–4. Ниже три способа сжать список; поля - те же, что отдаёт сервер (Quest: goal/target/progress, rarity, place, conditions, expiresAt, done/claimed, reward: gold/xp/orbs/guildXp).

Жёлтая пунктирная линия в телефоне - край первого экрана (360×800dp, над нижней навигацией); число «влезает» считается по ней автоматически.

A
Строка-лента 60dp

Иконка цели в кольце цвета редкости, имя в одну строку, тонкая полоса с «7 / 10», фишки наград числами-иконками; справа - кнопка «Сдать», штамп «✓» или таймер. Место, условия, полные награды и «Отказаться» - по касанию, строка раскрывается вниз. + Плотнее всех при сохранённых вкладках, полоса прогресса видна у каждого. − Названия сфер видны только в раскрытой строке; условия - значком.

СТРОКА

  • 60dp фикс: 30dp иконка, имя 13sp, полоса 4dp, фишки 11sp.
  • Готово - зелёная кайма + «Сдать» 30dp; сдано - серым, штамп ✓; истекает (< 1 ч) - таймер жёлтым.
  • Касание раскрывает: «Где», ◆ условия, все фишки (сфера → карточка), «Отказаться».

ДЛЯ КОДА

  • QuestRow(compact = true) + AnimatedVisibility деталей, ключ раскрытой строки в rememberSaveable.
  • Иконка цели - по quest.goal из ForgeGlyphs; вкладки и сервер не меняются.
B
Двухстрочная карточка

Строка 1 - точка редкости, имя, «7 / 10». Строка 2 - фишки наград (золото, опыт, сфера с названием), значки условий и места, таймер. Прогресс - кромкой 3dp по низу карточки; кнопка справа на обе строки. + Ближе всего к нынешнему виду, ничего не прячется за касанием кроме описания сюжета. − Влезает меньше, чем в A и C; длинные награды режутся «+1».

КАРТОЧКА

  • ~58dp: две строки по 20dp + отступы 8/10, кромка-полоса 3dp.
  • Условия - значок в синей рамке ModBlue (♥ без смерти, ① за один заход), место - значок ◉ с названием по долгому нажатию.
  • Кнопки доски «Сбросить»/«Взять» - справа, «Отказаться» - свайпом влево или долгим нажатием.

ДЛЯ КОДА

  • Замена тела QuestRow: два Row, QuestBar 3dp в Modifier.drawBehind по низу.
  • RewardChips(limit = 3) с «+N» вместо FlowRow.
C
Таблица с группами

Одна лента вместо трёх вкладок: группы «Готово к сдаче» (с «Сдать все»), «В процессе», «Контракты N/3», «Доска», «Сдано» (свёрнуто). Строка 42dp: метка вида Д/Н/К, имя, мини-полоса, главная награда, шеврон; детали - раскрытием. + Влезает больше всего, всё готовое к сдаче - сверху одним касанием. − Новая структура экрана, «Сдать все» - новое действие (вызов claim по каждому или серверный claimAll); видна только главная награда.

ЛЕНТА

  • Строка 42dp (длинное имя - в две строки, 56dp), заголовок группы 22dp; «Сдано» свёрнуто в одну строку.
  • Метка вида: Д - ежедневное, Н - недельное, К - контракт; сброс дня/недели - в подписи группы.
  • Раскрытие: полная полоса, «Где», условия, все фишки, кнопки.

ДЛЯ КОДА

  • Segments уходят (или остаются фильтром «Все / День / Неделя / Контракты»).
  • «Сдать все» - клиентом последовательно (сервер не меняется) или новым методом сервера - решить владельцу.
