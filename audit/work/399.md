# #399 Выключать ускорение движения героя после босса
Пакет: Забег и обновление; статус: решено; сервер: нет; дизайн: нет (SwitchRow, Mark уже есть)

## Разбор
Суть: после босса шаг героя ×2 (`bossSlainSpeed` 2.0, `campaign.json:10381`) без выключателя.
Причина: флаг `swift` в `ExpeditionRun.kt:285-293` ставится в `bossSlain()` и обратно не снимается; `heroSpeed(rules, stats, bossSlain)` `ExpeditionWorld.kt:506`; UI - только метка «×N» `MapMarks.kt:82-97`. Сервер движение не меряет.
Предложение: 1 (рекомендую) - настройка `GameSettings.swiftAfterBoss` (устройство) + переключатель в меню забега `RunMenu.kt:171-178` и по касанию метки «×N»; `rebody()` при смене; 2 - только команда в заходе без памяти; 3 - только настройки.

## Вопросы и ответы
1. Где переключатель? A (рекомендовал) настройка + меню забега + касание метки «×N» / B настройка + меню / C только кнопка без памяти. Ответ: A
2. По умолчанию? A (рекомендовал) включено / B выключено. Ответ: A
3. Метка при выключенном? A (рекомендовал) серая с подсказкой «ускорение выключено» / B пропадает. Ответ: A

## Решение
Настройка GameSettings.swiftAfterBoss = true (устройство); heroSpeed учитывает swift && настройка; переключатель SwitchRow в меню забега и в экране настроек; касание метки «×N» переключает; при выключенном метка серая с подсказкой. Пересчёт скорости (rebody) при смене настройки. Ключи локали ru/en, RULES.md:108.
