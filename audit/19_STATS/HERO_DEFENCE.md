Сервер этих характеристик сам не читает: только через `rules` (лист `SheetCalculator`, `Might`, `ResistBalance`). Потребители - бой клиента (`Combatant`, `BattleLand`, `BattleStrikes`, `BattleTick`, `EnergyShield`), карта/дорога (`MapEffects`, `RoadLife`, `HeroCarry`), сводка (`CombatSheet` + `StatLimits`) и Мощь (`Might`).

## Метод

- Свод: лист героя `ModifierMath.apply` (kind PERCENT - увеличение прибавкой, иначе множителем; MORE - множителем), строки боя `StatLines.fold`, монстр `MonsterRoller.fold` (всегда `(база+ADD)×(1+ΣINC)×ΠMORE`, kind не смотрит). Общие характеристики `GenericStat` (ALL_RESISTANCES, AVOID_ELEMENTAL_AILMENTS) раскладывает на членов только лист.
- Источники - сканер всего контента (семейства `modifiers.json` → пулы `tables.json`, узлы `tree.json`, уникалки `equipment.json`, силы, умения, трейты/фазы/тотемы/дары Разлома `campaign.json`, законы `quests.json`, Предначертание `fates.json`). Макс. ролл - верх сетки/вершины семейства; «дерево Σ» - сумма значений всех узлов (если взять всё).
- Тест: `StatsDefAuditTest` в копии клиента `/home/user/audit/work/stats-def/EF/core/src/test/kotlin/com/sperance/exileforge/core/audit/StatsDefAuditTest.kt` - реальный `Battle`/`Combatant`/`afflict`/`EnergyShield`/`SheetCalculator`/`MonsterRoller` правил. Метки в колонке «тест»:
  - **Д** - метаморфная дуэль: герой и монстр по 1e6 жизни, по 100 урона каждого из 5 видов, 2 удара/с, шансы недугов 30, накопления 20000; 40 с, шаг 0.05, сиды 101..106 против 201..206 для оценки шума; сдвиг показан, если >10% и >3× шума. Характеристику ставят то герою, то монстру (H.* - на герое, M.* - на монстре; lost - потеря запаса, ail - секунды под недугом, mag - ∫силы, held - время в удержании).
  - **А** - прямой `afflict` по каждому недугу (длительность, сила, `held`, `dotRate`, доли восстановления), оба направления.
  - **Ш** - лёд шкалы (`buildup` включён в `campaign.json`): шкала 0.999 + удар холодом.
  - **С** - 4000 чар напрямую `strike(spell=true)`.
  - **Р** - реген/щит/отложенный урон/подавление восстановления напрямую.
  - **Х** - шансы без насыщения (свой шанс 0 у обеих сторон), поджог хаосом против ЭЩ, срок отложенного урона.
  - **Л** - лист: каждое семейство с этой характеристикой через `SheetCalculator.raw`, свёртки `ModifierMath`/`StatLines`/`MonsterRoller`.

## [STAT-DEF-01] Лёд шкалы заморозки не слушает ни одной длительности
- **Категория:** BUG · **Приоритет:** P2 · **Уверенность:** высокая (тест) · **Подсистема:** бой клиента, накопления (3.78.0)
- **Файлы:** `ExileForge/core/.../combat/BattleLand.kt:192` (`val held = if (rarity == UNIQUE) effect.bossDuration else effect.duration`), `BattleLand.kt:218` (шанс заморозки не бросается при `buildup`), `Combatant.kt:190,253`; `campaign.json` → `combat.buildup: {}` (включено, `BuildupRule.freeze = 2.0/1.2 с`).

- **Факт:** лёд, наложенный шкалой (основной путь заморозки - и героя, и монстров), всегда 2.0 с (босс 1.2 с). `FREEZE_DURATION_ON_SELF`, `FREEZE_DURATION`, `AILMENT_DURATION` действуют только на заморозку, которую накладывает умение (`Blow.ailments`/`burden`; в `skills.json` их 3, в `powers.json` 5).
- **Доказательство (Ш):** `FREEZEBAR M->H [def FREEZE_DURATION_ON_SELF 60] frozen=true dur=2.0`, `[atk FREEZE_DURATION+100] dur=2.0`, `[atk AILMENT_DURATION+100] dur=2.0` - как `[base] dur=2.0`; для сравнения `AIL H->M FROZEN [def FREEZE_DURATION_ON_SELF 50] dur 0.8→0.4`, `[atk FREEZE_DURATION+100] 0.8→1.6`.

- **Варианты:** (а) в `buildUp` множить `held` на `target.body.ailmentDuration(FROZEN) × body.ailmentDurationOnFoes(FROZEN)` (тот же потолок 75%); (б) оставить лёд фиксированным, а строки переименовать в «заморозки от умений» и убрать аффиксы из пулов; (в) перевести длительности заморозки на `buildup.immunity`/порог шкалы (по-PoE2: длительность льда фиксирована, но растёт накопление).

- **Регрессионный тест:** шкала 0.999 + удар холодом: длительность льда с `FREEZE_DURATION_ON_SELF 60` = 2.0×0.4, с `FREEZE_DURATION 100` = 4.0.

## Прочие наблюдения (не дефекты)

- Урон во времени не режется сопротивлениями/«получаемым уроном» на тике: сила DoT берётся от уже смягчённой доли удара (`afflict`: `amount = taken[type]`), на тике - только шок, DOT_TAKEN, *_TAKEN. Сопротивление действует один раз - так задумано (KDoc).
- `IMMUNE_FREEZE` закрывает и охлаждение (имя «Невосприимчивость к холоду» - верно).
- `RECOVERY_RATE` ускоряет реген ЭЩ, но не перезарядку (`EnergyShield.recovered`), как в PoE.
- Монстр получает 50% своего блока атак в блок чар (`combat.monsterSpellBlock`), герой - нет (тест С: 40 → 18.9%) - по замыслу 4.6.2.
- Шанс недуга монстра = шанс правила (30/35/40/15) + стат; героя = `heroChance` 0 + стат (тест Х) - по замыслу.
- Отрицательные значения: сопротивления до −50 (`resistFloor`) работают как уязвимость; MAX_* с минусом (уник. −5, карта HERO_MAX_RESIST) снижают потолок; `*_DURATION_ON_SELF` < 0 отбрасывается (длительность не растёт); `*_TAKEN` < −100 → 0 (недуг без силы); `SHIELD_OF_LIFE` < 0 → 0.
